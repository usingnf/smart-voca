## 2. 배경과 목적

- 영어 단어를 외울 때 뜻을 찾고, 시험으로 확인하고, 복습 일정을 관리하는 과정이 여러 도구로 나뉘어 있다.
- 이 앱은 암기, 시험, 일일 과제, 보고서를 한 프로그램에서 처리하여 학습 흐름을 끊지 않게 하는 것을 목적으로 한다.
- 학습 기록은 사용자별로 저장하여 오답이 많은 단어를 다시 출제하고, 기간별 보고서로 학습 상태를 보여 준다.

## 3. 범위

### 3.1 포함 (In Scope)

- 사용자 계정 생성·선택·삭제·초기화 (FR-01, FR-11)
- 단어 암기, 단어 추가, 단어 검색 (FR-02, FR-01, FR-10)
- 시험 (방향·유형 선택, 문항 생성·채점) (FR-03, FR-06, FR-07)
- 일일 영단어 과제와 미이수 처리 (FR-04)
- 오답률 집계 (FR-05)
- 이력 저장과 HTML 보고서 (FR-08, FR-09)
- 한글 검색어에 대한 온라인 영어 번역 보조 검색 (FR-12)
- Windows 단일 `.exe` 배포

### 3.2 제외 (Out of Scope)

- 여러 기기 간 동기화, 서버 저장, 다중 사용자 동시 접속
- 모바일·웹 버전
- 음성 발음 기능의 고도화 (현재는 Windows 음성 기능을 보조로 사용)
- 로그인 인증 (계정은 이름으로 구분하며 비밀번호를 쓰지 않음)

> 위 제외 항목은 요구사항 명세서에 없는 내용이므로, 추가하려면 명세서를 먼저 고친다 (CLAUDE.md 원칙).

## 5. 제약 사항

- **언어·플랫폼**: Python 3.11, Windows 11 전용 (PyQt6, Windows 음성·글꼴 의존)
- **데이터**: 로컬 CSV와 JSON만 사용. 외부 DB 없음.
- **외부 호출**: 온라인 검색은 국립국어원 한국어기초사전 API에만 호출하며, 실패해도 로컬 기능은 동작해야 함.
- **라이선스**: 단어 데이터는 Kaikki(English Wiktionary 추출)의 CC BY-SA 4.0 / GFDL 조건을 따름. 출처를 행마다 기록.
- **개인정보**: 사용자 데이터·API 키는 저장소에 올리지 않음 (`.gitignore`).
- **일정**: 마감일 없음. 학습 목적이므로 완성도와 설명 가능성을 우선.
