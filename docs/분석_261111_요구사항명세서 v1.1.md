## 1. 개요

- **시스템명**: 스마트 보카 (클로드 스마트 보카)
- **목적**: 한글 사용자가 영어단어를 익히기 위해 도움을 주거나, 유사 의미의 단어를 빠르게 찾기 위한 도구
- **배포 형태**: 단일 `.exe` 파일 (Windows 11, PyQt6)
- **원본**: 사용자 작성 요구사항 문서 (`C:\Users\USER\Desktop\스마트보카_요구사항.MD`, 2026-10-21 반영)
- **추적성**: 각 기능에 ID(FR-xx)를 부여하여 구현과 연결한다 (방법론 §3-1).

## 3. 세부 규칙

### 3.1 날짜 기준 (FR-04, 2026-10-21 확정)

- 모든 날짜 계산은 **한국 표준시(KST, UTC+9)** 기준으로 한다. 과제의 날짜 경계는 KST 자정이다.
- **첫 과제 시작일**: 계정을 처음 만든 날의 KST 날짜부터 과제를 시작한다.

### 3.2 일일 과제 구성 (FR-04)

- 과제는 **복습 단어**와 **신규 단어**로 구성한다.
- 과제 총 단어 수는 **20개**로 한다.
- 복습 단어 비율은 과제마다 **10%~50% 범위에서 무작위**로 정한다.
- 복습 단어 수 = 과제 총 단어 수(20) × 복습 비율을 **반올림**한 값. 나머지는 모두 **신규 단어 수**로 한다.
  (예: 비율 33% → 복습 7개, 신규 13개)
- 복습 단어는 **전날 암기한 단어**에서 뽑는다.
- 신규 단어는 `voca.csv` 4000개 중 **무작위로** 뽑고, 이미 출제된 단어는 제외한다.
- 신규 단어를 모두 쓴 뒤에는 **오답률이 높은 단어부터** 복습 단어로 다시 출제한다.

### 3.3 과제 완수 기준 (FR-04)

- 과제는 **시험을 통과해야** 완수된다. 통과 기준은 **정답률 80% 이상**이다.
- 완수되지 않은 과제는 미이수로 본다 (3.4 참조).
- 과제 시험은 **오늘 과제 단어 20개 전체를 1회 시험**으로 치른다. 문항 유형은 단답형·4지선다·OX를 **균등 배분**한다.
  (예: 20문항 → 단답 7, 4지선다 7, OX 6)
- 나누어 떨어지지 않으면 **앞 유형부터 1문제씩 더 배분**한다. (예: 7문항 → 단답 3, 4지선다 2, OX 2)
- 정답률 = 정답 수 ÷ 문항 수. 20문항 기준 16개 이상 정답이면 통과한다.
- 시험을 끝까지 치르지 않고 나가면 **미이수**로 기록한다.

### 3.4 미이수 처리 (FR-04)

- 전날 과제를 완수하지 못하면 해당 과제를 **미이수**로 기록한다.
- 미이수된 과제는 **다음 날로 이어진다**. 미이수 과제의 단어는 **다음 날 복습 단어로 편입**한다.
- **편입 상한**: 다음 날 복습 단어 수는 복습 비율 상한(50%, 최대 10개)을 넘지 않는다. 상한을 넘는 편입 단어는 다음 날 복습에 넣지 않고 **그다음 날로 이월**한다. 이월은 편입 상한 안에 들 때까지 날마다 반복한다.
- 복습 단어 후보는 편입 단어를 먼저 채우고, 부족하면 전날 암기한 단어에서 무작위로 채운다.

### 3.5 복습 단어 부족 시 (FR-04)

- 복습 단어가 비율만큼 없으면 부족분을 **신규 단어로 채운다**. 과제 총 단어 수 20개는 유지한다.

### 3.6 오답률 (FR-05)

- 단위는 **단어 단위**다. 세션·사용자 전체 단위로 집계하지 않는다.
- 저장 항목: 단어별 출제 횟수, 오답 횟수, 오답률(오답 횟수 ÷ 출제 횟수).
- 오답률은 사용자별로 별도 저장한다.

### 3.7 정답 판정 (FR-03, FR-07)

- **대소문자와 띄어쓰기는 정답 판정에서 제외**한다. (예: `Apple`, `apple`, ` app le ` 모두 같은 답으로 처리)
- **복수 정답을 허용**한다. 단어 하나에 등록된 여러 한글 뜻 또는 여러 영어 표현 중 하나라도 일치하면 정답이다.

### 3.8 오답 확인 (FR-03)

- 시험에서 오답을 입력하면, **최종 결과 화면에서 정답을 확인**할 수 있어야 한다.

### 3.9 단어 추가 규칙 (FR-01, 2026-10-21 확정)

- 단어 추가는 **사용자가 영단어와 한글 뜻을 직접 입력**한다. 사전 데이터에서 자동으로 채우지 않는다.
- 추가한 단어는 목록에 저장하고 `voca.csv` 형식에 맞춰 기록한다. 출처 열에는 "사용자 입력"으로 표시한다.
- 이미 있는 단어를 다시 입력하면 **경고를 띄운 뒤 뜻을 합친다**(중복 뜻은 제거).
- 단어 목록 불러오기는 **`voca.csv` 형식만** 지원한다.

### 3.10 사용자 계정 (FR-01, FR-05, FR-08, 2026-10-21 확정)

- 로그인은 **사용자명만 입력**한다. 비밀번호는 없다.
- 같은 사용자명은 같은 계정으로 본다.
- 단어 목록, 오답률, 이력은 **사용자별로 분리**해 저장한다.
- 사용자명은 **영문·숫자·한글 1~20자**, 대소문자를 구분하지 않는다.

### 3.11 계정 선택 (FR-01, 2026-10-21 확정)

- 프로그램을 실행할 때마다 **사용자명을 입력**한다. 마지막 계정은 기억하지 않는다.

### 3.12 단어 데이터 규칙 (2026-10-21 확정)

- **한글 뜻이 없는 단어는 제외**한다. `voca.csv`와 사용자 추가 단어 모두 적용한다.
- 뜻이 부족하거나 부정확한 단어는 **그대로 두고**, 사용자가 수정할 수 있게 한다.

### 3.13 유사 의미 단어 규칙 (FR-10, 2026-10-21 확정)

- 데이터 출처는 **Kaikki 데이터의 유의어(`synonyms`) 항목**이다.
- 검색 입력은 **영어 단어와 한글 뜻 모두 가능**하다.
- 한글 뜻으로 검색하면 해당 뜻을 가진 단어를 찾은 뒤 그 단어의 유의어를 보여 준다.
- **검색 대상 범위**: `voca.csv` 4000개 단어 + 사용자가 추가한 단어. 후보 풀(13,316개) 전체는 검색하지 않는다.
- 유의어는 `voca.csv`에 **`유의어` 열**을 추가해 저장한다. 별도 데이터 파일을 두지 않으므로 exe 옆에 둘 파일은 `voca.csv`와 이력 파일 두 개뿐이다.
- 대상 단어 목록 밖의 단어는 검색 결과가 없다고 표시한다. 범위 확장은 추후 결정한다 (5-3).

### 3.14 온라인 한영 보조 검색 규칙 (FR-12, 2026-10-28 확정)

- 외부 호출 허용. 대상 API는 **국립국어원 한국어기초사전 검색 API**(`https://krdict.korean.go.kr/api/search`)다. 추가 요금 없음, 하루 50,000건 한도.
- 요청: `key`, `q`(한글 검색어), `part=word`, `translated=y`, `trans_lang=1`(영어). 응답은 XML이며 표준 라이브러리로 파싱한다.
- **보조 기능**이다. 기존 로컬 검색(FR-10) 결과를 대체하지 않는다. 로컬 결과를 먼저 보여 주고, 온라인 결과는 별도 영역에 표시한다.
- 한글 검색어에만 호출한다. 영어 검색어는 API가 한글 표제어 기준이므로 호출하지 않는다 (영→한은 로컬 뜻으로 처리).
- **인증키**는 코드에 넣지 않고 exe 옆 `settings.json`의 `krdict_api_key`에 저장한다. 키가 없으면 온라인 검색을 건너뛰고 안내 문구만 표시한다.
- **오프라인 처리**: 인터넷 연결이 없거나, 시간 초과(5초), 한도 초과, 인증 오류가 나면 **로컬 결과만 출력**한다. 오류로 프로그램이 멈추지 않는다.
- 호출은 **백그라운드 스레드**에서 실행한다. 입력 후 짧은 지연(디바운스) 뒤에만 호출한다.
- 같은 검색어의 온라인 결과는 메모리에 캐시한다. 이력 파일이나 `voca.csv`에는 저장하지 않는다.
- **이용 조건 (저작권 정책 페이지 확인, 2026-10-28)**: 별도 명시가 없는 자료는 **크리에이티브 커먼즈 저작자표시-동일조건변경허락 2.0 대한민국(CC BY-SA 2.0 KR)**으로 배포된다. 상업적 이용 가능, 저작자 표시 필수, 변경 저작물은 같은 라이선스로 배포해야 한다.
- 온라인 결과를 보여 줄 때마다 `online_dict.ATTRIBUTION_TEXT` 출처 문구를 함께 표시한다. 온라인 결과를 파일로 저장하지 않는다.
- 공공누리(KOGL) 유형과 멀티미디어(발음 등) 파일별 정책은 이 기능에서 쓰지 않으므로 확인 대상이 아니다.

### 3.15 배포 규칙 (2026-10-21 확정)

- 배포물은 **단일 `.exe` 파일 하나**다.
- `voca.csv`와 이력 파일은 **exe와 같은 폴더**에 둔다. 경로는 실행 파일 위치 기준으로 계산한다 (`sys.executable`, `sys.frozen` 사용).
- 두 파일은 exe에 포함(번들)하지 않는다. PyInstaller 임시 폴더(`_MEIPASS`)를 데이터 경로로 쓰지 않는다.
- 파일은 **백업 기능 없이** 저장한다. 저장할 때는 임시 파일에 먼저 쓴 뒤 원본을 교체해 손상 위험을 줄인다.

### 3.16 계정 삭제·초기화 규칙 (FR-11, 2026-10-21 확정)

- **계정 삭제**: 해당 사용자의 단어 목록, 오답률, 이력, 과제 상태를 모두 지운다. 계정 자체가 사라진다.
- **초기화**: 오답률, 이력, 과제 상태를 지운다. 계정과 사용자가 추가한 단어 목록은 남긴다.
- 두 기능 모두 실행 전에 **확인 창**을 띄우고, 확인을 눌러야 실행한다.
- 삭제·초기화는 되돌릴 수 없음을 확인 창에 표시한다.
- exe는 **사용자가 쓰기 가능한 폴더**(예: `C:\SmartVoca\`)에 둔다. `Program Files` 등 쓰기 제한 폴더에 두지 않는다.

### 3.17 이력·보고서 규칙 (FR-08, FR-09, 2026-10-21 확정)

- 이력은 **CSV 형식**, **사용자별 파일 하나**로 저장한다.
- 보고서는 **HTML**로 만들어 기본 브라우저에서 연다.
- 기간 필터는 **전체 + 기간 선택**을 지원한다.
- 보고서 포함 항목: **과제 이수율, 오답률 상위 단어, 암기한 단어 수**.
- "오답률 상위 단어"는 **상위 10개**만 보여 준다.
- 출제 0회인 단어의 오답률은 **"-"로 표시**하고, 순위에서 제외한다.

### 3.18 암기 규칙 (FR-02, 2026-10-21 확정)

- 암기 기능은 **시험이 아니다**. 채점, 정답률, 과제 완수 판정에 쓰지 않는다.
- 사용자는 **영어 단어 또는 한글 뜻 중 하나를 먼저 보고**, 대응하는 답(뜻 또는 단어)을 **클릭해서 연다**.
- 암기 이력(열어 본 단어, 시각)은 FR-08 이력 파일에 기록한다. 오답률에는 반영하지 않는다.
- **"암기했다"의 정의**: 단어를 열어 본 것을 암기로 본다. 복습 단어는 전날 열어 본 단어에서 뽑는다.

### 3.19 시험 규칙 (FR-03, FR-06, FR-07, 2026-10-21 확정)

- **문제 수**: 기본 20문제, 선택 범위 5~50문제 (5 단위).
- **시간 제한**: 없음. 문항당 시간 제한을 두지 않는다.
- **방향 선택**: 한글→영어, 영어→한글, 복합 중 선택. 복합은 문제마다 두 방향을 **50:50**으로 섞는다.
- **문제 유형 선택**: 단답형, 4지선다형, OX형 중 선택. 혼합 선택 시 유형을 **균등 배분**한다.
- **4지선다**: 정답 1개 + 오답 3개, 보기 순서는 무작위.
- **OX**: 정답 **O 50%, X 50%**. X 문항은 정답이 아닌 뜻으로 만든다.
- **오답 보기 선택 규칙 (4지선다·OX 공통)**
  1. **같은 품사**의 단어에서만 뽑는다. (예: 명사 문제의 오답은 명사 단어의 뜻)
  2. 같은 품사 후보 중 **철자가 비슷한 단어**를 우선한다. 철자 유사도는 `difflib.SequenceMatcher` 비율로 계산하고, 상위 후보에서 무작위로 고른다.
  3. 정답 뜻과 **겹치는 뜻**(같은 한글 뜻 포함)을 가진 단어는 오답 후보에서 제외한다.
  4. 같은 품사 후보가 부족하면 전체 단어에서 뽑는다.
