## 4. 완료 기준 (Definition of Done)

1. 해당 FR의 규칙이 명세서 세부 규칙과 일치한다.
2. 단위 테스트가 추가되고 전체 테스트가 통과한다 (`python -m unittest discover -s tests -v`).
3. 명세서 추적 매트릭스에 구현 위치가 남아 있다.
4. 큰 작업은 작업 일지를 남긴다.
5. 커밋 메시지는 Conventional Commits를 따른다.
