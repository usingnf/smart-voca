# 웹 실행 안내 (Operations Manual)

**파일 위치**: `ai-agent/claude/261118_웹버전/운영_261118_웹 실행 안내 v1.0.md` (승인 후 `docs/` 승격 예정)
**작성일**: 2026-11-18
**버전**: v1.0
**설명**: 웹 버전을 이 PC에서 실행하고 문제를 해결하는 방법. 방법론 §2.4 운영 매뉴얼의 웹 부분.

---

## 1. 준비

| 항목 | 확인 방법 |
|------|-----------|
| Python 3.11 | `py -3.11 --version` |
| 패키지 설치 | `py -3.11 -m pip install -r requirements.txt` |
| 단어 파일 | `data/voca.csv` (4000개) 존재 |

> `requirements.txt`에 웹 실행용 `fastapi`, `uvicorn`, `httpx`가 포함되어 있다 (2026-11-18 추가). 설치 명령 한 번으로 모두 준비된다.

## 2. 실행

프로젝트 루트(`Smart-Voca` 폴더)에서 실행한다.

```
python web/run.py
```

- 서버 주소는 `http://127.0.0.1:8765/`이다.
- 실행하면 기본 브라우저가 자동으로 열린다 (1.5초 뒤).
- 종료는 실행 창에서 `Ctrl+C`를 누른다.
- 실행 창을 닫으면 서버도 종료되고, 진행 중인 시험은 사라진다 (기록되지 않는다).

## 3. 데이터 위치

| 항목 | 위치 |
|------|------|
| 단어 | `data/voca.csv` |
| 계정별 기록 | `data/users/<계정>/` |
| 설정(인증키 포함) | `data/settings.json` |
| 보고서 HTML | 웹에서는 만들지 않음 (exe 전용) |

- 다른 폴더를 쓰려면 실행 전에 환경 변수를 지정한다.
  ```
  set SMARTVOCA_DATA_DIR=D:\내보카데이터
  python web/run.py
  ```
- 웹 데이터와 exe 데이터(`dist/` 옆 폴더)는 따로 저장된다. 한쪽에서 만든 계정은 다른 쪽에 보이지 않는다.

## 4. 자주 생기는 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| `Address already in use` | 8765 포트를 다른 프로그램이 사용 중 | 이전 서버 창을 닫는다. 그래도 안 되면 `web/run.py`의 `PORT` 값을 바꾼다 |
| `단어 파일을 찾을 수 없습니다` | `data/voca.csv` 없음 | 파일 위치를 확인하거나 `SMARTVOCA_DATA_DIR`을 맞춘다 |
| `ModuleNotFoundError: fastapi` | 웹 패키지 미설치 | 1장의 pip 명령을 실행한다 |
| 브라우저가 자동으로 안 열림 | 기본 브라우저 설정 | 주소 `http://127.0.0.1:8765/`를 직접 입력한다 |
| 화면이 옛날 모습 | 브라우저 캐시 | `Ctrl+F5`로 강력 새로고침한다 |
| 온라인 검색 안내만 나옴 | 인증키 없음 또는 인터넷 없음 | 옵션에서 키를 입력한다. 인터넷 연결을 확인한다 |
| 새로고침 후 계정을 다시 고름 | 정상 동작 (명세서 3.11) | 계정 관리에서 다시 고른다 |
| 400 `사용자명은 영문·숫자·한글 1~20자` | 계정 이름 형식 오류 | 허용 문자만 쓴다 |
| 404 `계정을 찾을 수 없습니다` | 계정이 없음 | 계정 관리에서 새로 만든다 |

## 5. 보안 주의

- 서버는 이 PC에서만 접속할 수 있다 (`127.0.0.1`).
- `data/settings.json`에는 온라인 검색 인증키가 들어 있다. 이 파일을 다른 사람에게 보내지 않는다.
- 공용 PC에서는 계정 선택 화면만으로 보호되지 않는다. 같은 PC를 쓰는 사람은 다른 계정의 기록을 볼 수 있다.

## 6. 점검 명령 (개발자용)

```
python -m unittest discover -s tests -v
```

웹 API 시나리오는 임시 폴더에서 실행되므로 실제 기록을 바꾸지 않는다.
