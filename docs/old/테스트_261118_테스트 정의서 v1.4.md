## 4. BDD 시나리오

### 4.1 과제 완수 (FR-04)

```
시나리오: 80% 이상 맞히면 과제가 완수된다
  Given 오늘 과제가 20개 단어로 만들어져 있다
  When  과제 시험에서 16문제 이상 맞힌다
  Then  과제 상태가 completed가 된다

시나리오: 중간에 나가면 미이수가 된다
  Given 오늘 과제가 있다
  When  과제 시험을 끝까지 치르지 않고 나간다
  Then  과제 상태가 missed가 되고 다음 날 복습으로 이월된다
```

대응 테스트: `test_pass_threshold_is_eighty_percent`, `test_missed_assignment_carries_over`

### 4.2 같은 날 과제 (FR-04)

```
시나리오: 같은 날 다시 열어도 과제가 바뀌지 않는다
  Given 오늘 과제가 이미 만들어져 있다
  When  오늘 과제를 다시 요청한다
  Then  같은 단어 20개가 반환된다
```

대응 테스트: `test_same_day_returns_same_assignment`

### 4.3 시험 채점 (FR-03)

```
시나리오: 대소문자와 공백을 무시하고 채점한다
  Given 정답이 "apple"인 단어가 있다
  When  사용자가 " APPLE "를 입력한다
  Then  정답으로 판정된다

시나리오: 뜻이 여러 개면 하나만 맞아도 정답이다
  Given 한글 뜻이 "사과, 능금"이다
  When  사용자가 "능금"을 입력한다
  Then  정답으로 판정된다
```

대응 테스트: `test_grading_ignores_case_and_spaces`, `test_multiple_meanings_are_all_accepted`

### 4.4 4지선다 오답 보기 (FR-07)

```
시나리오: 오답 보기는 정답과 뜻이 겹치지 않는다
  Given 정답 단어와 후보 단어 풀이 있다
  When  4지선다 문항을 만든다
  Then  오답 보기 3개의 뜻이 정답 뜻과 겹치지 않는다
```

대응 테스트: `test_choice_distractors_never_share_meaning`

### 4.5 중복 암기 기록 (FR-02, FR-08)

```
시나리오: 같은 날 같은 단어를 여러 번 열어도 기록은 한 번이다
  Given 단어 "abacus"를 오늘 이미 열었다
  When  같은 단어를 다시 연다
  Then  이력에 행이 추가되지 않는다
```

대응 테스트: `test_same_word_same_day_adds_history_only_once`

### 4.6 온라인 검색 실패 (FR-12)

```
시나리오: 인증키가 없으면 네트워크를 쓰지 않는다
  Given 인증키가 비어 있다
  When  온라인 검색을 요청한다
  Then  네트워크 호출 없이 안내 메시지가 반환된다

시나리오: 실패한 조회는 캐시하지 않는다
  Given 이전 조회가 실패했다
  When  같은 검색어로 다시 조회한다
  Then  다시 요청한다
```

대응 테스트: `test_missing_key_is_reported_without_network_call`, `test_failed_lookup_is_not_cached`

### 4.7 처리되지 않은 오류 (공통)

```
시나리오: 잡히지 않은 예외는 로그 파일에 기록된다
  Given 오류 처리기가 설치되어 있다
  When  예외가 발생한다
  Then  로그 파일에 예외 종류와 메시지가 추가된다

시나리오: 로그 쓰기에 실패해도 프로그램은 계속 실행된다
  Given 로그 파일 경로가 폴더로 막혀 있다
  When  기록을 시도한다
  Then  False가 반환되고 예외는 던지지 않는다

시나리오: Ctrl+C는 기록하지 않는다
  Given 오류 처리기가 설치되어 있다
  When  KeyboardInterrupt가 발생한다
  Then  로그 파일이 만들어지지 않는다
```

대응 테스트: `test_handler_writes_exception_to_log_without_dialog`, `test_write_failure_returns_false_instead_of_raising`, `test_keyboard_interrupt_is_not_logged`

#### 4.8 단어 가져오기 (FR-01, VOCA-FR-003)

```
시나리오: 기존 단어와 같은 파일 안의 중복은 건너뛴다
  Given 기본 단어 abacus가 있다
  When  "plimbox,상자", "abacus,수판", "plimbox,중복", "123,숫자"를 가져온다
  Then  plimbox 1개가 추가되고, 2개가 건너뛰어지며, 5번째 줄이 형식 오류로 보고된다
```

대응 테스트: `BulkAddTests.test_existing_and_duplicate_words_are_skipped`, `test_import_words_adds_new_and_skips_existing`

### 4.9 가중 출제 (FR-03, VOCA-FR-022)

```
시나리오: 안 본 단어가 더 자주 출제된다
  Given 후보 100개 중 10개는 출제 기록이 없고, 나머지는 최근에 두 번 출제되었다
  When  10문항씩 200번 고른다
  Then  안 본 단어가 균등 추출(10%)보다 뚜렷하게 많이 뽑히고, 한 시험 안에서 같은 단어는 없다
```

대응 테스트: `WeightedTestTests.test_picks_are_unique_and_favor_never_asked_words`

### 4.10 자주 틀린 단어 섞기 (FR-04, VOCA-FR-013)

```
시나리오: 복습 단어에 자주 틀린 단어가 섞인다
  Given 전날 암기 단어 10개와 오답률이 높은 단어 2개가 있다
  When  복습 단어 10개를 고른다
  Then  오답률이 높은 단어 2개가 포함되고, 전날 암기 단어도 일부 남는다
```

대응 테스트: `ReviewMixTests.test_review_includes_frequently_wrong_words`
