**작성일**: 2026-11-18
**버전**: v1.0
**설명**: 단어 CSV, 사용자별 파일, 설정 파일, 오류 로그의 스키마와 저장 정책을 정리한 설계서. 방법론 §2.3 데이터 설계 산출물. DB를 쓰지 않고 파일로 저장하는 구조다.

## 2. 단어 원본 `voca.csv`

### 2.1 열 정의

| 열 이름 | 상수 (`vocab.py`) | 필수 | 설명 | 예 |
|---------|-------------------|------|------|----|
| 단어 | `COLUMN_WORD` | 예 | 영어 표제어 | `abacus` |
| 품사 | `COLUMN_POS` | 예 | `noun`, `verb`, `adj`, `adv`, `other` | `noun` |
| 한글뜻 | `COLUMN_MEANING` | 예 | 쉼표(`, `)로 연결, 최대 3개 | `수판, 산판, 셈판` |
| 영문뜻 | `COLUMN_GLOSS` | 아니오 | 첫 번째 영문 정의 | |
| 출처 | `COLUMN_SOURCE` | 예 | 원천 표시 | `kaikki.org (English Wiktionary 추출, 2026-09-02 덤프)` |
| 라이선스 | `COLUMN_LICENSE` | 예 | 라이선스 표시 | `CC BY-SA 4.0 / GFDL` |
| 유의어 | `COLUMN_SYNONYM` | 아니오 | 쉼표 연결, 최대 10개 | `civet hyena, earthwolf` |
| 예문 | `COLUMN_EXAMPLE` | 아니오 | 영문 예문 한 개 | |

### 2.2 규칙

- 인코딩은 UTF-8이며 BOM을 포함한다 (`utf-8-sig`로 읽는다).
- 한 행이 한 단어다. 같은 단어가 여러 품사로 있으면 행을 나눈다 (품사 필터 테스트에서 확인).
- 셀 안 줄바꿈은 허용한다. 현재 73개 셀에 줄바꿈이 있다 (2026-11-18 확인).
- 열 순서는 `CSV_COLUMNS`를 따른다. 열을 바꾸면 `data/README.md`와 수집 스크립트를 함께 고친다.

### 2.3 현재 값 (2026-11-18 확인)

| 항목 | 값 |
|------|----|
| 데이터 행 수 | 4,000 |
| 유의어 있음 | 2,530 |
| 예문 있음 | 2,940 |

## 3. 사용자별 파일

### 3.1 `state.json` (상태)

| 키 | 형식 | 의미 |
|----|------|------|
| `assignments` | 목록 | 과제 기록. 각 항목은 `date`, `words`, `review`, `new`, `status`, `score` |
| `queue` | 목록 | 미이수 과제 이월 대기열 |
| `stats` | 객체 (단어 → 시도·오답 수) | 오답률 계산 근거 (FR-05) |
| `memorized` | 객체 (날짜 → 단어 목록) | 날짜별 암기 단어. 다음 날 복습 후보 |

- 생성 기본값은 `user_store.empty_state()`가 정한다.
- 과제 `status`는 `pending`, `completed`, `missed` 중 하나다 (`config.STATUS_*`).

### 3.2 `words.csv` (사용자 추가 단어)

- 공용 `voca.csv`와 같은 열 구조를 쓴다 (`WordEntry`를 `entry_to_row`로 변환).
- 사용자별 파일이므로 다른 사용자와 섞이지 않는다.
- 초기화(FR-11)는 이 파일을 지우지 않는다 (`test_reset_keeps_custom_words`).

### 3.3 `history.csv` (이력)

| 열 | 설명 | 예 |
|----|------|----|
| 일시 | KST 시각, ISO 8601 형식 (초 단위, 시간대 포함) | `2026-11-18T09:12:00+09:00` (예시) |
| 구분 | `config.RECORD_*` 중 하나 | `암기`, `시험`, `과제시험` |
| 단어 | 대상 단어 | `abacus` |
| 방향 | `quiz.DIRECTION_*` | `영어→한글` |
| 유형 | `quiz.KIND_*` (암기는 비움) | `4지선다형` |
| 결과 | `config.RESULT_*` | `정답`, `오답`, `열람` |
| 입력값 | 사용자가 입력한 답 | |
| 정답 | 정답 뜻 | |

- 시험으로 집계하는 구분은 `config.TEST_RECORD_KINDS` (`시험`, `과제시험`)다.
- 암기 이력은 오답률에 넣지 않는다 (명세서 3.18).
- 같은 날 같은 단어 암기는 한 번만 기록한다 (`test_same_word_same_day_adds_history_only_once`).

## 4. 설정 파일 `settings.json`

| 키 | 타입 | 기본값 | 범위 |
|----|------|--------|------|
| `theme` | 문자열 | `밝게` | `밝게`, `어둡게` |
| `font_size` | 정수 | 10 | 9~16 |
| `exam_count` | 정수 | 20 | 5~50, 5 단위 |
| `exam_direction` | 문자열 | `영어→한글` | 3가지 |
| `memorize_direction` | 문자열 | `영어→한글` | 2가지 |
| `window_width` / `window_height` | 정수 | 900 / 600 | 800~2560 / 540~1600 |
| `krdict_api_key` | 문자열 | 빈 값 | 앞뒤 공백 제거 |
| `online_lookup_enabled` | 불리언 | true | |
| `exam_kinds` | 목록 | 3가지 전부 | 알려진 값만 |
| `exam_pos_keys` | 목록 | 5가지 전부 | 알려진 값만 |
| `exam_favorites_only` | 불리언 | false | |

- 범위를 벗어난 값은 `AppSettings.sanitized()`가 기본값으로 되돌린다.
- 잘못된 값이 있어도 앱은 종료하지 않는다.

## 5. 오류 기록 `error.log`

- 형식: `[YYYY-MM-DD HH:MM:SS]` 시각 줄, 다음 줄부터 트레이스백.
- 파일이 없으면 폴더와 함께 만든다. 쓰기에 실패하면 기록을 건너뛴다.
- 사용자 학습 데이터는 기록하지 않는다.

## 6. 저장 정책

| 항목 | 정책 |
|------|------|
| 쓰기 방식 | JSON은 임시 파일(`*.json.tmp`)에 쓴 뒤 교체 |
| 손상 파일 | 형식 오류 시 `quarantine_file`로 옮기고 새 상태로 시작 |
| 백업 | 자동 백업은 없음. 이력은 `export_history`로 사용자가 내보낼 수 있음 |
| 삭제 | 계정 삭제는 사용자 폴더 전체를 지움 (FR-11). 되돌릴 수 없음 |
| 용량 | 이력은 행 단위로 쌓이며 자동 정리는 없음 |

## 7. 무결성 규칙

1. 단어 키는 `WordEntry.word`다. 사용자 추가 단어가 공용 단어와 같으면 중복 안내를 띄운다 (`AddWordPage`).
2. 계정 폴더 이름은 소문자로 정규화하여 대소문자 차이를 없앤다.
3. 과제는 날짜당 하나다. 같은 날 다시 호출하면 기존 과제를 반환한다 (`test_same_day_returns_same_assignment`).
4. 완수된 과제의 점수는 `complete_assignment`에서만 기록한다.

## 8. 알려진 한계

- 뜻별 구분이 없는 유의어가 섞여 있을 수 있다 (`data/README.md` 5장).
- CSV는 열 이름이 바뀌면 읽기가 깨진다. 열 이름은 상수로 관리한다.
