# 인터페이스 정의서 (Integration Spec)

**파일 위치**: `docs/설계_261118_인터페이스 정의서 v1.2.md`
**작성일**: 2026-11-18
**버전**: v1.2
**설명**: 구성 요소 사이의 호출 규격(화면↔세션, 세션↔저장소, 저장소↔DB), 환경 변수, 외부 API 전문 규격을 정리한 정의서. 방법론 §2.3 인터페이스 정의 산출물. v1.1에서 저장소 인터페이스를 SQLite 기준으로 바꾸고 환경 변수 규격을 추가했다.

---

## 1. 내부 인터페이스

### 1.1 화면 → 세션 (`UserSession`)

화면은 `UserSession` 객체만 호출한다. 저장소와 업무 로직을 직접 호출하지 않는다.

| 메서드 | 입력 | 출력 | 용도 |
|--------|------|------|------|
| `add_word(word, pos, meanings)` | 단어, 품사, 뜻 목록 | 합쳤으면 True | 사용자 단어 추가 |
| `update_custom_word` / `delete_custom_word` | 단어 | 결과 | 사용자 단어 수정·삭제 |
| `exists_word(word)` / `is_custom_word(word)` | 단어 | 불리언 | 중복 안내, 수정 가능 여부 |
| `toggle_favorite(word)` / `is_favorite(word)` | 단어 | 불리언 | 즐겨찾기 |
| `favorite_pool()` | 없음 | 단어 풀 | 즐겨찾기 전용 시험 |
| `today_assignment()` | 없음 | 과제 | 오늘 과제 (없으면 생성) |
| `pending_today()` | 없음 | 과제 또는 None | 미완수 과제 확인 |
| `finish_assignment(assignment, results)` | 과제, 채점 결과 목록 | 통과 여부 | 과제 완수 처리 |
| `abandon_assignment(assignment)` | 과제 | 없음 | 중단 시 미이수 기록 |
| `record_memorize(word)` | 단어 | 없음 | 암기 열람 기록 |
| `record_results(results, kind_label)` | 결과 목록, 구분 문자열 | 없음 | 시험 결과 기록 |
| `wrong_words()` | 없음 | 단어 목록 | 오답 재시험 대상 |
| `reset_records()` | 없음 | 없음 | 기록 초기화 (FR-11) |
| `delete_account()` | 없음 | 없음 | 계정 삭제 (FR-11) |
| `export_history(target_path)` | 경로 | 기록했으면 True, 이력이 없으면 False | 이력을 CSV 파일로 저장 (데스크톱) |
| `history()` | 없음 | 이력 행 목록 | 보고서 입력, 웹 이력 내려받기 |
| `add_words_bulk(words, pos="other")` | (영단어, 뜻 목록) 목록 | `{added, skipped}` | CSV 가져오기 (v1.2) |
| `progress(today)` | 날짜 | `{day, memorized, total}` | 일차와 암기 진도 (v1.2) |

**규칙**
- 호출 전 입력은 화면에서 검사한다 (예: 계정 이름 형식, 문항 수 범위).
- 세션은 저장 후 상태를 DB에 반영한다 (`save`).

### 1.2 세션 → 저장소 (`user_store`, `settings`)

| 모듈 | 함수·클래스 | 입력 | 출력 |
|------|-------------|------|------|
| `user_store` | `UserStore(username_key, db_path=None)` | 계정 키, DB 경로 (없으면 `DB_PATH`) | 계정 데이터 접근 객체 |
| `user_store` | `UserStore.create()` / `exists()` / `delete()` | 없음 | 없음 / 불리언 / 없음 |
| `user_store` | `UserStore.reset()` | 없음 | 없음 (이력과 상태를 지우고 추가 단어는 남김) |
| `user_store` | `UserStore.load_state()` / `save_state(state)` | 없음 / 상태 사전 | 상태 사전 / 없음 |
| `user_store` | `UserStore.load_custom_words()` / `save_custom_words(entries)` | 없음 / `{단어: WordEntry}` | `{단어: WordEntry}` / 없음 |
| `user_store` | `UserStore.append_history(rows)` | 이력 행 목록 (한글 열 이름, `일차` 열 선택) | 없음 |
| `user_store` | `UserStore.read_history()` | 없음 | 이력 행 목록 (한글 열 이름, 기록 순서) |
| `user_store` | `user_exists(key, db_path=None)` | 계정 키 | 불리언 |
| `user_store` | `list_user_keys(db_path=None)` | 없음 | 계정 키 목록 (정렬) |
| `user_store` | `normalize_username(raw_name)` | 문자열 | 정규화 키 또는 None |
| `user_store` | `history_csv_bytes(rows)` | 이력 행 목록 | CSV 바이트 (UTF-8 BOM) |
| `settings` | `load_settings(db_path=None)` | DB 경로 | `AppSettings` (없거나 깨졌으면 기본값) |
| `settings` | `save_settings(settings, db_path=None)` | 설정, DB 경로 | 없음 (범위 검사 후 저장) |
| `database` | `transaction(db_path=None)` | DB 경로 | 연결 (블록 끝에 저장, 오류 시 되돌림) |
| `database` | `connect(db_path=None)` / `ensure_schema(db_path=None)` | DB 경로 | 연결 / 없음 (테이블 자동 생성) |

- 계정 키는 소문자 정규화 값이다. 저장소 함수는 정규화를 다시 하지 않는다.
- `db_path`를 주면 테스트용 임시 DB를 쓴다.

## 2. 외부 인터페이스: 한국어기초사전 검색 API

### 2.1 요청

| 항목 | 값 |
|------|----|
| 방식 | HTTP GET |
| 주소 | `https://krdict.korean.go.kr/api/search` |
| 제한 시간 | 5초 (`REQUEST_TIMEOUT_SECONDS`) |
| 인증 | 쿼리 파라미터에 인증키 포함 (`build_search_url`) |

| 파라미터 | 값 | 설명 |
|----------|----|------|
| `key` | 사용자 인증키 | `settings.krdict_api_key` (`app_settings`에 저장) |
| `q` | 검색어 (한글) | 사용자 입력 |
| `part` | `word` | 표제어 기준 검색 |
| `translated` | `y` | 번역 결과 요청 |
| `trans_lang` | `1` | 영어 번역 (`KRDICT_TRANS_LANG_ENGLISH`) |
| `num` | 10 | 결과 수 (`KRDICT_RESULT_NUM`) |

> 파라미터 이름의 세부 값은 `src/online_dict.py`의 `build_search_url`이 정한다. 이 표는 현재 코드 기준이며, 공식 문서와 다르면 공식 문서를 따른다.

### 2.2 응답

- 형식: XML, UTF-8.
- 추출 대상: 번역 항목의 영어 표현. 번역이 없는 항목은 건너뛴다.
- 중복 표현은 한 번만 남긴다.
- 오류 응답(인증 실패 등)은 `OnlineDictError`로 바꾼다.

### 2.3 오류 처리

| 상황 | 예외 메시지 (`online_dict.py`) | 화면 처리 |
|------|-------------------------------|-----------|
| 인증키 없음 | `MSG_NO_KEY` (옵션 화면에서 입력하라는 안내) | 안내 후 로컬 결과만 표시. 네트워크 호출 없음 |
| 인터넷 없음, 연결 실패 | `MSG_OFFLINE` | 안내 후 로컬 결과만 표시 |
| 시간 초과 | `MSG_OFFLINE`과 같이 처리 | 같음 |
| HTTP 오류 | `온라인 서버 오류 (HTTP 코드)` | 안내 메시지 |
| XML 파싱 실패 | `OnlineDictError` | 안내 메시지 |

### 2.4 출처 표시 (필수)

- 결과 화면에 `ATTRIBUTION_TEXT`를 표시한다: "출처: 국립국어원 한국어기초사전 (크리에이티브 커먼즈 저작자표시-동일조건변경허락 2.0 대한민국)".

## 3. 파일·DB 인터페이스

### 3.1 단어 CSV (`voca.csv`)

- 위치: 환경 변수 `VOCA_PATH`가 있으면 그 경로, 없으면 데이터 폴더의 `voca.csv`.
- 열 구조와 값 규칙은 `데이터 설계서 v1.1` 2장을 따른다.
- 앱은 이 파일을 읽기만 한다. 쓰는 것은 수집 스크립트(`ai-agent/scripts/`)다.
- BOM(`utf-8-sig`)이 있으므로 읽을 때 첫 열 이름이 깨지지 않도록 `utf-8-sig`로 읽는다.

### 3.2 사용자 DB (`voca.db`, SQLite)

- 위치: 환경 변수 `DB_PATH`가 있으면 그 경로, 없으면 데이터 폴더의 `voca.db`.
- 테이블 구조는 `데이터 설계서 v1.1` 3장을 따른다: `users`, `user_state`, `custom_words`, `history`, `app_settings`.
- 외래 키 규칙을 켜서 연결하며, 계정 삭제 시 딸린 행이 함께 지워진다.
- 테이블은 처음 연결할 때 `CREATE TABLE IF NOT EXISTS`로 만든다. 같은 파일에서는 프로세스당 한 번만 확인한다.
- 연결 대기 시간은 10초다.

### 3.3 옵션 (`app_settings` 표)

- 행 한 개(`id = 1`)에 옵션 전체를 JSON 문자열(`settings_json`)로 저장한다.
- 키 이름은 `AppSettings` 필드 이름과 같다 (snake_case). 저장 시 `ensure_ascii=False`.
- 데스크톱 옵션 화면과 웹 옵션 화면은 같은 행을 읽고 쓴다.

### 3.4 환경 변수 규격

| 이름 | 값 | 기본값 | 쓰는 곳 | 설명 |
|------|----|--------|---------|------|
| `SMARTVOCA_DATA_DIR` | 폴더 경로 | exe 옆 폴더 또는 `data/` | `config.py` | 데이터 폴더. `voca.db`, `reports/`의 기준이 된다 |
| `DB_PATH` | 파일 경로 | 데이터 폴더의 `voca.db` | `config.py` | SQLite 파일 위치. 서버 배포는 `/data/voca.db` |
| `VOCA_PATH` | 파일 경로 | 데이터 폴더의 `voca.csv` | `config.py` | 단어 CSV 위치. 서버 배포는 `/app/data/voca.csv` |
| `ALLOWED_HOSTS` | 쉼표로 구분한 호스트 이름, 또는 `*` | 로컬 실행은 빈 값, 서버 이미지는 `*` | `web/app.py` | 웹 서버가 받을 Host 이름을 더한다. `*`는 모든 이름을 받는다. 예: `example.school.ac.kr` |
| `SECRET_KEY` | 문자열 | 사용하지 않음 | 없음 | 세션 기능이 없어 아직 읽지 않는다 |

- 공백만 있는 값은 없는 것으로 본다.
- 로컬 실행에서 허용 목록에 없는 Host로 들어오면 `400 Bad Request`가 나온다. 서버 이미지는 기본값 `*`라서 앞단 프록시의 Host 이름도 받는다.

## 4. 오류 기록 인터페이스

| 항목 | 값 |
|------|----|
| 함수 | `crash_log.install_crash_handler()` → `sys.excepthook` 교체 |
| 기록 위치 | `ERROR_LOG_PATH` |
| 기록 형식 | `[시각]` 줄 다음에 트레이스백 |
| 안내 창 | `QMessageBox.critical` (QApplication이 있을 때만) |
| 제외 | `KeyboardInterrupt`는 기본 처리 |

## 5. 변경 규칙

1. 인터페이스 이름이나 입력·출력을 바꾸면 이 문서와 테스트를 같이 고친다.
2. 외부 API 규격이 바뀌면 `online_dict.py`와 이 문서를 함께 고친다.
3. 화면이 세션 외 객체를 직접 호출하는 곳이 생기면 설계 위반으로 보고 정리한다 (현재 `main.py`는 예외).
4. 테이블 구조를 바꾸면 `데이터 설계서`와 기존 `voca.db` 이관 절차(운영 정의서 9장)를 함께 고친다.
