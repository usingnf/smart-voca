| 항목 | 내용 | 근거 |
|------|------|------|
| 제공처 | kaikki.org (Wiktextract 추출 결과) | `data/README.md` 2장 |
| 덤프 날짜 | 2026-09-02 | `data/README.md` |
| 라이선스 | **확인 필요.** 프로젝트 문서는 CC BY-SA 4.0 / GFDL로 기재했으나 원문에서 확인되지 않음 (아래 참조) | `data/README.md` 3장 |
| 재배포 조건 | **확인 필요.** 출처 표시 요구는 kaikki.org의 인용 요청으로만 확인됨 | kaikki.org/dictionary/rawdata.html |

| 추출 조건 | 영어 표제어, 소문자 3~12자, 명사·동사·형용사·부사, 한국어 번역 1개 이상 | `data/README.md` 4장 |

**라이선스 확인 결과 (2026-11-18, WebFetch로 원문 확인)**

| 출처 | 확인된 내용 |
|------|-------------|
| [kaikki.org 원시 데이터 안내](https://kaikki.org/dictionary/rawdata.html) | 라이선스 문구 없음. 학술 연구에 쓰면 Tatu Ylonen의 논문을 인용하고, kaikki.org 링크를 걸어 달라는 요청만 있음. 이 페이지는 "enwiktionary dump dated 2026-10-01"을 안내하며, 프로젝트가 쓴 덤프는 2026-09-02임 |
| [wiktextract 저장소 LICENSE](https://github.com/tatuylonen/wiktextract/blob/master/LICENSE) | 소프트웨어는 MIT License. `tests/` 파일만 Wiktionary 라이선스(CC-BY-SA 또는 GFDL 선택)를 따름. 데이터 출력물에 대한 조항은 없음 |

**해석**: CC BY-SA 4.0 / GFDL은 Wiktionary 원문 콘텐츠의 라이선스다. 그러나 kaikki.org 추출물에 그대로 적용된다는 명시는 확인하지 못했다. 따라서 `voca.csv`의 출처·라이선스 열은 출처 기록으로 남기되, 라이선스 항목은 **확인 필요**로 둔다. 재배포 전에 원 저작물 조건과 kaikki.org의 최신 안내를 다시 확인해야 한다.

## 2. 외부 API 분석

### 2.1 국립국어원 한국어기초사전 검색 API

| 항목 | 내용 | 근거 |
|------|------|------|
| 주소 | `https://krdict.korean.go.kr/api/search` | `src/online_dict.py` |
| 용도 | 한글 검색어의 영어 번역(`translated=y`, `trans_lang=1`) 조회 | 일지 `일지_261028_온라인한영검색.md` |
| 인증 | 사용자가 발급받은 인증키 (`settings.json`의 `krdict_api_key`) | `src/settings.py` |
| 응답 형식 | XML | `parse_search_xml` |
| 시간 초과 | 5초 | `REQUEST_TIMEOUT_SECONDS` |
| 출처 표시 | "국립국어원 한국어기초사전 (CC BY-SA 2.0 대한민국)" | `ATTRIBUTION_TEXT` |
| 요금 | 공식 안내 기준 무료 (2026-10-28 확인 기록) | 일지 |
| `trans_lang` 값 | **확인 필요.** 검색으로 공식 가이드의 값을 찾지 못함. 현재 코드 값 `1`은 일지 기록 기준 | `src/online_dict.py` |

> 검색으로 확인되지 않은 항목: `trans_lang` 파라미터의 허용 값과 정확한 이름. 공식 가이드는 인증키 발급 후 열람 가능하므로 실제 키로 한 번 호출해 응답을 확인해야 한다.

**해석**: 키가 없거나 인터넷이 없으면 앱은 실패 메시지만 보여 주고 로컬 결과로 계속 동작한다. 외부 의존을 보조 기능으로 제한한 설계다.

### 2.2 외부 호출 정책

- 호출은 사용자가 검색할 때만 발생한다. 앱 시작 시 자동 호출은 없다.
- 설정 화면에서 온라인 검색을 끌 수 있다 (`online_lookup_enabled`).
- 실패한 조회는 캐시하지 않는다 (`tests/test_ui_fixes.py`의 `test_failed_lookup_is_not_cached`).

## 3. 기술 환경 분석

### 3.1 실행 환경

| 항목 | 현황 | 비고 |

### 3.2 기술 선택의 외부 조건

| 조건 | 영향 |
|------|------|
| 단일 exe 배포 | 데이터 파일을 exe 옆에 두어야 함 (`BASE_DIR` 규칙) |
| 콘솔 없는 실행 (`--windowed`) | 오류가 보이지 않음 → 오류 기록 기능 필요 |
| 로컬 사용자 데이터 | 사용자 간 데이터 격리는 폴더 단위로만 보장 |
| 음성 기능 (`speech.py`) | Windows 전용 명령에 의존 |

### 3.3 Windows 특이 사항 (CLAUDE.md 기록)

- 오프스크린 렌더링(`QT_QPA_PLATFORM=offscreen`)에서는 Windows 글꼴을 읽지 못해 한글이 깨진다. 화면 캡처는 `QT_QPA_PLATFORM=windows`로 한다.

## 4. 유사 사례 분석

**상태: 1차 조사 완료 (2026-11-18, WebSearch).** 검색 결과는 주로 블로그와 비교 사이트이므로, 세부 가격과 기능은 참고용이다. 실제 확인은 각 앱의 최신 안내에서 해야 한다.

### 4.1 간격 반복 암기 앱

| 앱 | 무료 여부 | 간격 반복 | 특징 | 본 프로젝트와의 차이 |
|----|-----------|-----------|------|----------------------|
| [Anki](https://www.heuristi.ca/compare/anki-vs-quizlet) | 데스크톱·안드로이드 무료, iOS 유료 | 기본 SM-2, FSRS 선택 가능 | 간격 반복의 기준으로 평가됨. 학습 곡선이 가파름 | 본 앱은 하루 과제 단위이고, 복습 주기가 고정 규칙(전날 암기 단어)이다 |
| [Quizlet](https://studycardsai.com/quizlet-vs-anki) | 광고 있는 무료판, 간격 반복은 유료 Plus | 유료 전용 | 사용이 가장 쉬움. 사용자 제작 덱의 품질이 들쭉날쭉함 | 본 앱은 단어 데이터가 한 벌로 고정되어 있고, 시험 결과로 과제 완수를 판정한다 |
| [Memrise](https://www.mindomax.com/anki-vs-memrise) | 무료판 제한 | 간격 반복 + 멀티미디어 | 원어민 영상 클립을 함께 제공 | 본 앱은 영상 없이 텍스트 중심이다 |

**시사점**: 간격 반복 앱은 대부분 "언제 복습할지"를 알고리즘으로 정한다. 본 앱은 "전날 암기 + 신규 + 오답 보충"이라는 단순 규칙을 쓴다. 이 규칙은 계산이 투명해 학생이 설명하기 쉽다는 장점이 있다. 반면 복습 간격을 개별 단어마다 조정하지는 못한다.

### 4.2 한영 사전·유의어 앱

| 앱 | 유의어 | 비고 |
|----|--------|------|
| [Korean Dictionary (Innovative-Software)](https://www.fluentu.com/korean/blog/korean-dictionary-app/) | 있음 (동의어·반의어) | 한국어 사전 중심으로 소개됨. 무료 |
| [Korean to English & English to Korean Dictionary](https://apps.apple.com/us/app/id1195285669) | 시소러스 기능 있음 | iOS 전용, 평점 3.2 |
| [Korean English Dictionary & Translator](https://apps.apple.com/app/id874164556) | 목록에 명시되지 않음 | 예문과 와일드카드 검색 지원 |
| [KoEnDic 한영/영한 사전](https://apps.apple.com/app/id577707937) | 목록에 명시되지 않음 | 약 20만 항목, iOS 전용 |

**시사점**: 유의어를 함께 보여 주는 한영 사전 앱은 드물다. 본 앱은 유의어(Kaikki 데이터, 2530개 행)와 온라인 한영 보조 검색을 한 화면에서 제공한다는 점이 차별점이다. 다만 유의어는 뜻별로 나뉘지 않아 정확도가 떨어질 수 있다 (`data/README.md` 5장).

### 4.3 시험 생성 도구

- 시험 생성 도구는 조사에서 별도로 다루지 않았다. Quizlet, Anki의 시험 기능을 참고 대상으로 본다.
- 본 앱의 문항 유형(단답형, 4지선다형, OX형)과 방향 선택(영→한, 한→영, 복합)은 위 앱들과 비교해 구현 범위가 명확하다.

### 4.4 조사 한계

- 검색 결과 대부분이 블로그와 비교 사이트이며, 공식 문서가 아니다.
- 가격과 기능은 조사 시점 기준이며 변동될 수 있다.
- 실제 앱을 직접 사용해 비교하지는 않았다.

## 5. 법적·보안 환경

- **라이선스**: Kaikki 데이터는 **확인 필요** (1.1 참조). 한국어기초사전 API는 출처 표시 조건(CC BY-SA 2.0 대한민국)을 따른다.
- **인증키**: `settings.json`은 저장소 제외 대상이다 (`.gitignore`).
- **개인정보**: 계정 이름만 저장한다. 실명·연락처는 입력받지 않는다.
