**라이선스 확인 결과 (2026-11-18, 원문 확인)**

| 출처 | 확인된 내용 |
|------|-------------|
| [kaikki.org 원시 데이터 안내](https://kaikki.org/dictionary/rawdata.html) | 라이선스 문구 없음. 학술 연구에 쓰면 Tatu Ylonen의 논문을 인용하고, kaikki.org 링크를 걸어 달라는 요청만 있음. 이 페이지는 2026-10-01 덤프를 안내함 |
| [wiktextract 저장소 LICENSE](https://github.com/tatuylonen/wiktextract/blob/master/LICENSE) | 소프트웨어는 MIT License. `tests/` 파일만 Wiktionary 라이선스(CC-BY-SA 또는 GFDL 선택)를 따름. 데이터 출력물에 대한 조항은 없음 |

**해석**: CC BY-SA 4.0 / GFDL은 Wiktionary 원문 콘텐츠의 라이선스다. kaikki.org 추출물에 그대로 적용된다는 명시는 확인하지 못했다. 따라서 `voca.csv`의 출처·라이선스 열은 출처 기록으로 남기되, 라이선스 항목은 확인 필요로 둔다. 재배포 전에 원 저작물 조건과 kaikki.org의 최신 안내를 다시 확인해야 한다 (작업 계획서 T-15).

## 2. 외부 API 분석

### 2.1 국립국어원 한국어기초사전 검색 API

| 항목 | 내용 | 근거 |
|------|------|------|
| 주소 | `https://krdict.korean.go.kr/api/search` | `src/online_dict.py` |
| 용도 | 한글 검색어의 영어 번역 조회 (`translated=y`, `trans_lang=1`) | 일지 `일지_261028_온라인한영검색.md` |
| 인증 | 사용자가 발급받은 인증키. 웹은 환경 변수 `KRDICT_API_KEY`, 데스크톱은 옵션 화면 입력값(DB 옵션 `krdict_api_key`) | `online_dict.load_krdict_api_key`, `src/settings.py` |
| 응답 형식 | XML | `parse_search_xml` |
| 시간 초과 | 5초 | `REQUEST_TIMEOUT_SECONDS` |
| 출처 표시 | "국립국어원 한국어기초사전 (CC BY-SA 2.0 대한민국)" | `ATTRIBUTION_TEXT` |
| 요금 | 공식 안내 기준 무료 (2026-10-28 확인 기록) | 일지 |
| `trans_lang` 값 | **확인 필요.** 공식 가이드는 인증키 발급 후 열람 가능. 검색으로는 확인하지 못함 [미확인] | `src/online_dict.py` |

**해석**: 키가 없거나 인터넷이 없으면 앱은 실패 메시지만 보여 주고 로컬 결과로 계속 동작한다. 외부 의존을 보조 기능으로 제한한 설계다.

### 2.2 외부 호출 정책

- 호출은 사용자가 검색할 때만 발생한다. 앱 시작 시 자동 호출은 없다.
- 설정 화면에서 온라인 검색을 끌 수 있다 (`online_lookup_enabled`).
- 실패한 조회는 캐시하지 않는다 (`tests/test_ui_fixes.py`의 `test_failed_lookup_is_not_cached`).

**시사점**
- Anki는 간격 반복은 강하지만 시험 문항을 자동으로 만들지 않는다. 본 앱의 시험 기능(단답형, 4지선다형, OX형)은 Anki에 없는 부분이다.
- Quizlet은 시험 기능을 갖추고 있지만 무료 범위에 제한이 있다는 점이 2차 출처에서 반복된다. 본 앱은 시험 문항을 로컬에서 무제한으로 만들 수 있다는 점이 차별점이다.
- 본 앱은 알고리즘 대신 단순 규칙(전날 암기, 신규, 오답 보충)을 쓴다. 계산이 투명해 설명하기 쉽지만, 단어마다 복습 간격을 조정하지는 못한다.

### 4.3 시험 생성 도구 (신규 조사)

| 도구 | 제공 문항 유형 | 방향·채점 방식 | 자동 생성 여부 | 검증 |
|------|----------------|----------------|----------------|------|
| Quizlet Test 모드 | 단답(직접 입력), 객관식, OX, 매칭 (매칭은 제3자 사이트 설명에만 있음) | 채점 후 틀린 답 표시 (2차 출처) | 세트의 단어에서 자동 생성 (2차 출처) | 객관식의 Plus 전용 여부는 공식 도움말 접근 실패로 **[미확인]** |

**본 앱과의 비교**
- 본 앱의 시험은 세 가지 유형(단답형, 4지선다형, OX형)을 쓰고, 방향(영→한, 한→영, 복합)을 고를 수 있다. 4지선다 오답 보기는 정답 뜻과 겹치지 않고 같은 품사를 우선하도록 설계했다 (`프로세스 설계서` 3장).
- Quizlet Test는 문항 유형이 섞여 나온다는 점이 비슷하다. 차이는 본 앱이 과제 완수 기준(정답률 80%)과 오답 기반 재출제를 함께 쓴다는 점이다.

**연구 근거 (2차 출처, 서지 정보 미확인)**: 학습법 연구를 종합한 리뷰에서 연습 시험(practice testing)과 분산 연습(distributed practice)이 가장 높은 효과로 평가되었다는 요약이 검색되었다. 본 앱의 시험 중심 설계가 이 결과와 맞는다. 검색 요약에는 리뷰 논문의 저자와 연도가 없었으므로 서지 정보는 확인 전까지 적지 않는다. 원문 확인 후 출처를 추가한다.

### 4.4 조사 한계

- Quizlet의 공식 요금 페이지와 도움말 페이지에 접근하지 못했다(403). Quizlet의 가격과 무료 범위는 2차 출처에 근거하며, 출처마다 값이 다르다. 공식 확인 전까지 [미확인]으로 둔다.
- Memrise의 요금 페이지가 로드되지 않았다. 플랜명과 가격은 확인하지 못했다.
- App Store 정보는 조사 시점의 값이며 평점 표본이 작다(6~25건).
- 실제 앱을 직접 사용해 비교하지는 않았다.

## 5. 법적·보안 환경

- **라이선스**: Kaikki 데이터는 **확인 필요** (1.1 참조). 한국어기초사전 API는 출처 표시 조건(CC BY-SA 2.0 대한민국)을 따른다.
- **인증키**: 저장소와 이미지에 넣지 않는다. 웹은 환경 변수로만 받는다. `.gitignore`는 DB 파일(`*.db`)과 `settings.json`을, `.dockerignore`는 같은 파일들을 제외한다 (v1.2).
- **개인정보**: 계정 이름만 저장한다. 실명·연락처는 입력받지 않는다.
