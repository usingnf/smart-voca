## 2. 기능 상세

### 2.1 계정 관리 (FR-01, FR-11)

| 원자 기능 | 설명 | 구현 위치 |
|-----------|------|-----------|
| 사용자명 검사 | 한글·영문·숫자 1~20자, 소문자 정규화 | `user_store.normalize_username` |
| 계정 생성 | 새 폴더와 빈 상태 파일 생성 | `UserStore`, `login_dialog.py` |
| 계정 선택 | 기존 계정 목록에서 고르기 | `LoginDialog` |
| 기록 초기화 | 이력·과제·오답률 삭제, 사용자 추가 단어는 유지 | `UserSession.reset_records`, `AccountPage` |
| 계정 삭제 | 사용자 폴더 전체 삭제 | `UserSession.delete_account`, `AccountPage` |

### 2.2 단어 관리 (FR-01, FR-10)

| 원자 기능 | 설명 | 구현 위치 |
|-----------|------|-----------|
| 단어 추가 | 사용자 단어 추가 (품사·뜻 입력) | `AddWordPage`, `UserSession.add_word` |
| 중복 안내 | 입력 중 기존 단어 표시 | `AddWordPage` |
| 단어 수정·삭제 | 사용자 추가 단어만 대상 | `UserSession.update_custom_word`, `delete_custom_word` |
| 즐겨찾기 | 단어 표시와 시험 대상 필터 | `UserSession.toggle_favorite` |
| 영어 검색 | 영단어 기준 검색 | `vocab.search_by_english` |
| 뜻 검색 | 한글 뜻 기준 검색 | `vocab.search_by_meaning` |
| 유의어 표시 | 검색 결과에 유의어 목록 | `SearchPage`, `vocab.WordEntry.synonyms` |

### 2.3 암기 (FR-02)

| 원자 기능 | 설명 | 구현 위치 |
|-----------|------|-----------|
| 단어 열기 | 뜻을 가리고 한 단어씩 열기 | `MemorizePage` |
| 열람 기록 | 같은 날 같은 단어는 이력에 한 번만 기록 | `UserSession.record_memorize`, `test_ui_fixes.py` |
| 방향 선택 | 영어→한글, 한글→영어 | `settings.memorize_direction` |
| 키보드 조작 | 첫 입력은 답 열기, 다음 입력은 다음 단어 | `MemorizePage` (테스트: `MemorizeKeyboardTests`) |

### 2.4 시험 (FR-03, FR-06, FR-07)

| 원자 기능 | 설명 | 구현 위치 |
|-----------|------|-----------|
| 문항 수 선택 | 5~50, 5 단위 | `config.EXAM_QUESTION_*`, `TestPage` |
| 방향 선택 | 영어→한글, 한글→영어, 복합 | `quiz.DIRECTION_*`, `TestPage` |
| 유형 선택 | 단답형, 4지선다형, OX형 | `quiz.KIND_*`, `build_kind_sequence` |
| 품사 필터 | 선택한 품사만 출제 | `vocab.filter_by_pos` |
| 문항 생성 | 정답 뜻과 겹치지 않는 오답 보기 | `quiz.build_questions`, `pick_distractors` |
| 채점 | 대소문자·공백 무시, 여러 뜻 중 하나만 맞아도 정답 | `quiz.grade_answers`, `is_correct` |
| 오답 확인 | 틀린 문항과 정답 표시 | `QuizDialog` |
| 오답 재시험 | 틀린 단어만 다시 출제 | `QuizDialog`, `UserSession.wrong_words` |
| 결과 기록 | 구분(시험), 방향, 유형, 결과 저장 | `UserSession.record_results` |

### 2.5 일일 과제 (FR-04, FR-05)

| 원자 기능 | 설명 | 구현 위치 |
|-----------|------|-----------|
| 과제 생성 | 20개, 복습 비율 10~50% 무작위 | `daily.create_today_assignment`, `choose_review_count` |
| 복습 단어 선택 | 전날 암기 단어 | `daily.pick_review_words` |
| 신규 단어 선택 | 출제 이력 없는 단어 무작위 | `daily.pick_new_words` |
| 부족분 보충 | 오답률 높은 단어 | `daily.pick_high_error_words` |
| 미이수 이월 | 미이수 단어를 다음 날 복습으로 편입 (상한 적용) | `daily.close_overdue` |
| 과제 시험 | 20문항 1회, 유형 균등 배분 | `AssignmentPage`, `quiz.build_kind_sequence` |
| 완수 판정 | 정답률 80% 이상 | `daily.complete_assignment`, `config.PASS_RATE` |
| 오답률 집계 | 단어별 시도·오답 수 | `daily.error_rate`, `user_store` |

### 2.6 기록과 보고서 (FR-08, FR-09)

| 원자 기능 | 설명 | 구현 위치 |
|-----------|------|-----------|
| 이력 저장 | 일시, 구분, 단어, 방향, 유형, 결과, 입력값, 정답 | `UserStore.append_history`, `HISTORY_COLUMNS` |
| 기간 선택 | 전체, 최근 7일, 최근 30일, 직접 지정 | `report.period_range` |
| 집계 | 시험 정답률, 과제 완수율, 암기 수, 오답 상위 | `report.build_summary`, `top_wrong_words` |
| 날짜별 정답률 | 최근 14일 막대 그래프 | `report.daily_accuracy`, `ui/chart.py` |
| HTML 보고서 | `reports/`에 저장 | `report.write_report` |
| 이력 내보내기 | 선택한 경로로 복사 | `UserSession.export_history` |

### 2.7 온라인 보조 검색 (FR-12)

| 원자 기능 | 설명 | 구현 위치 |
|-----------|------|-----------|
| 검색 주소 만들기 | 인증키, 검색어, 번역 옵션 | `online_dict.build_search_url` |
| 응답 해석 | XML에서 영어 번역만 추출, 중복 제거 | `online_dict.parse_search_xml` |
| 조회 | 5초 시간 초과, 오프라인·HTTP 오류 처리 | `online_dict.search_english_translations` |
| 백그라운드 실행 | 화면 멈춤 방지 | `OnlineLookupWorker` |
| 결과 캐시 | 성공한 조회만 캐시 | `SearchPage` (테스트: `SearchOnlineCacheTests`) |
| 출처 표시 | 결과 아래 출처 문구 | `ATTRIBUTION_TEXT` |

### 2.8 옵션 (보조 기능)

| 원자 기능 | 설명 | 구현 위치 |
|-----------|------|-----------|
| 테마 | 밝게, 어둡게 | `settings.theme`, `ui/theme.py` |
| 글꼴 크기 | 9~16 | `settings.font_size` |
| 시험 기본값 | 문항 수, 방향, 유형, 품사, 즐겨찾기 전용 | `AppSettings`, `OptionsPage` |
| 온라인 검색 | 켜기·끄기, API 키 입력 | `OptionsPage` (테스트: `OptionsOnlineToggleTest`) |
| 창 크기 | 800~2560 × 540~1600 | `AppSettings.sanitized` |
