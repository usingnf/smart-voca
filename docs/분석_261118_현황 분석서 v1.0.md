## 1. 분석 기준

- 근거: 저장소 커밋 이력(`git log`), 소스 코드(`src/`, 3,437줄 + 테스트), 데이터(`data/voca.csv`, 단어 4,000개, `wc -l` 기준 4,132줄 — 줄바꿈이 포함된 셀이 있어 줄 수와 행 수가 다름), 문서(`docs/`, `ai-agent/claude/`), 실행 결과(단위 테스트 71개).
- 작업 기록은 `ai-agent/claude/` 일지와 커밋 메시지를 사용했다. 작업 당시의 구두 지시는 기록에 없으므로 이 분석에 포함하지 않았다.

## 2. 기존 비즈니스 프로세스 (사용자 관점)

1. 사용자 계정을 선택하거나 새로 만든다.
2. 오늘의 과제(복습 + 신규 단어 20개)를 확인한다.
3. 단어를 암기하거나 검색하여 뜻과 유의어를 본다.
4. 과제 시험을 치러 80% 이상 맞히면 과제를 완수한다.
5. 기간별 보고서로 학습 상태를 확인한다.

이 흐름은 명세서 FR-01~FR-11에 모두 대응된다.

## 3. 시스템 구조 현황

### 3.1 구성 요소

| 계층 | 주요 파일 | 역할 |
|------|-----------|------|
| 진입점 | `src/main.py` | 앱 시작, 로그인 창, 메인 창 연결 |
| 화면 (UI) | `src/ui/*.py` (9개 파일, 약 1,900줄) | PyQt6 창과 페이지 |
| 세션 (퍼사드) | `src/session.py` | 한 사용자의 상태를 다루며 화면은 이 객체만 호출 |
| 업무 로직 | `quiz.py`, `daily.py`, `report.py`, `vocab.py`, `online_dict.py` | 문항 생성·채점, 과제 구성, 보고서, 단어 검색, 온라인 조회 |
| 저장 | `user_store.py`, `settings.py`, `vocab.py` (CSV 읽기·쓰기) | JSON, CSV 파일 입출력 |
| 공통 | `config.py`, `timeutil.py`, `crash_log.py`, `speech.py` | 설정값, 날짜, 오류 기록, 음성 |

### 3.2 강점

- 화면이 세션 객체만 호출하므로 업무 로직을 화면 없이 테스트할 수 있다.
- 파일 쓰기는 임시 파일 후 교체 방식이라 중간 실패에 강하다.
- 설정값과 기록 종류 상수는 `config.py`에 모아 중복을 줄였다 (커밋 `874451b`).
- 요구사항 ID가 파일과 함수까지 연결되어 있다 (명세서 4장).

### 3.3 약점과 문제점

| 번호 | 현상 | 근거 | 영향 |
|------|------|------|------|
| P-1 | UI 파일 하나가 크다. `ui/study_pages.py` 547줄, `ui/quiz_dialog.py` 253줄 | `wc -l` | CLAUDE.md의 "500줄 넘으면 분리 제안" 기준 초과 (study_pages.py) |
| P-2 | 시험 기록 구분 상수가 과거에 여러 곳에 중복 정의되었다 | 커밋 `874451b` | 해결됨. 같은 종류의 문제를 막는 검사가 없음 |
| P-3 | 처리되지 않은 예외가 콘솔 없이 사라져 원인을 알기 어려웠다 | 커밋 `874451b`, `crash_log.py` | 해결됨 (로그 파일과 안내 창) |
| P-4 | exe 빌드 결과가 최신 소스보다 오래되었을 가능성 | `dist/SmartVoca.exe` 수정 시각 2026-11-11 15:11, 최신 커밋 15:16 | 오류 기록 기능이 exe에 빠져 있을 수 있음. 재빌드 필요 여부 확인 필요 |
| P-5 | 설계 문서가 `ai-agent/claude/`에만 있고 `docs/`에 승격되지 않았다 | 파일 위치 | 방법론 §2 산출물 기준으로 승인본이 부족 |
| P-6 | 일부 산출물(기획서, 테스트 정의서, ADR, 배포 정의서)이 별도 문서로 없었다 | `docs/` 목록 | 이번 작업에서 초안 작성 |
| P-7 | 작업 일지가 최신 커밋(`874451b`)에 대해 없다 | `ai-agent/claude/` 목록 | CLAUDE.md 원칙 "큰 작업 후 일지" 미준수 |
| P-8 | 단어 데이터의 뜻은 뜻별로 나뉘지 않고 합쳐져 있다 | `data/README.md` 5장 | 유의어 중 뜻과 맞지 않는 항목이 섞일 수 있음 |
| P-9 | 유의어 1470행, 예문 1060행이 비어 있다 | `data/README.md` 5장 | 검색 결과에 "없음" 표시 |
