# 웹 실행 안내 (Operations Manual)

**파일 위치**: `docs/운영_261118_웹 실행 안내 v1.2.md`
**작성일**: 2026-11-18
**버전**: v1.2
**설명**: 웹 버전(기본 실행 버전)을 이 PC에서 실행하고 문제를 해결하는 방법, 그리고 학교 서버 배포의 입구. 방법론 §2.4 운영 매뉴얼의 웹 부분. v1.1에서 웹을 기본 실행 버전으로 정하고, 데이터 위치를 SQLite(`voca.db`)로 바꾼 내용을 반영했다.

---

## 1. 준비

| 항목 | 확인 방법 |
|------|-----------|
| Python 3.11 | `py -3.11 --version` |
| 패키지 설치 | `py -3.11 -m pip install -r requirements.txt` |
| 단어 파일 | `data/voca.csv` (4000개) 존재 |

> `requirements.txt`에 웹 실행용 `fastapi`, `uvicorn`, `httpx`가 포함되어 있다. 설치 명령 한 번으로 모두 준비된다.
> 학교 서버 배포용 패키지 목록은 `requirements-server.txt`다 (PyQt6 제외). 서버 배포는 `운영_261118_배포·운영 정의서 v1.1.md` 5장을 따른다.

## 2. 실행

프로젝트 루트(`Smart-Voca` 폴더)에서 실행한다. 두 방법 중 하나를 쓴다.

```
python web/run.py
```

또는 `웹실행.bat`을 더블클릭한다. 패키지가 없으면 설치 안내를 띄운다.

- 서버 주소는 `http://127.0.0.1:8765/`이다.
- 실행하면 기본 브라우저가 자동으로 열린다 (1.5초 뒤).
- 종료는 실행 창에서 `Ctrl+C`를 누른다.
- 실행 창을 닫으면 서버도 종료되고, 진행 중인 시험은 사라진다 (기록되지 않는다).
- 로컬 실행은 이 PC에서만 접속할 수 있다. 학교 서버 배포는 별도 절차다.

## 3. 데이터 위치

| 항목 | 위치 |
|------|------|
| 단어 | `data/voca.csv` |
| 사용자 데이터 (계정, 상태, 추가 단어, 이력, 옵션) | `data/voca.db` (SQLite) |
| 보고서 HTML | 웹에서는 만들지 않음 (데스크톱 전용) |

- 계정별 폴더(`users/`)와 `settings.json`은 더 이상 만들어지지 않는다. 예전 파일이 남아 있으면 운영 정의서 9장의 절차로 `voca.db`에 옮긴다.
- 다른 위치의 DB를 쓰려면 실행 전에 환경 변수를 지정한다.
  ```
  set DB_PATH=D:\내보카데이터\voca.db
  python web/run.py
  ```
- 데이터 폴더 전체를 바꾸려면 `SMARTVOCA_DATA_DIR`을 쓴다. 이때 DB는 그 폴더의 `voca.db`가 된다 (`DB_PATH`를 따로 주면 그 값이 우선).
  ```
  set SMARTVOCA_DATA_DIR=D:\내보카데이터
  python web/run.py
  ```
- 웹과 exe는 DB 파일이 다르면 데이터를 공유하지 않는다. exe 옆 `voca.db`와 `data/voca.db`는 별개다.
- 온라인 한영 보조 검색을 쓰려면 실행 전에 환경 변수 `KRDICT_API_KEY`를 설정한다. 예: `set KRDICT_API_KEY=인증키` 후 `python web/run.py`. PowerShell은 `$env:KRDICT_API_KEY="인증키"`를 쓴다. 웹 화면에서는 키를 입력하지 않는다 (v1.2).

## 4. 자주 생기는 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| `Address already in use` | 8765 포트를 다른 프로그램이 사용 중 | 이전 서버 창을 닫는다. 그래도 안 되면 `web/run.py`의 `PORT` 값을 바꾼다 |
| `단어 파일을 찾을 수 없습니다` | `data/voca.csv` 없음 | 파일 위치를 확인하거나 `SMARTVOCA_DATA_DIR`, `VOCA_PATH`를 맞춘다 |
| `ModuleNotFoundError: fastapi` | 웹 패키지 미설치 | 1장의 pip 명령을 실행한다 |
| `unable to open database file` | `DB_PATH` 또는 데이터 폴더가 없거나 쓸 수 없음 | 폴더를 만들고 쓰기 권한을 확인한다 |
| 기존 계정이 안 보임 | 예전 파일 데이터가 `voca.db`에 아직 없음 | 운영 정의서 9장의 이관 절차를 실행한다 |
| 브라우저가 자동으로 안 열림 | 기본 브라우저 설정 | 주소 `http://127.0.0.1:8765/`를 직접 입력한다 |
| 화면이 옛날 모습 | 브라우저 캐시 | `Ctrl+F5`로 강력 새로고침한다 |
| 온라인 검색 안내만 나옴 | 환경 변수 `KRDICT_API_KEY` 없음 또는 인터넷 없음 | 실행 전에 `KRDICT_API_KEY`를 설정한다. 인터넷 연결을 확인한다 |
| 새로고침 후 계정을 다시 고름 | 정상 동작 (명세서 3.11) | 계정 관리에서 다시 고른다 |
| 400 `사용자명은 영문·숫자·한글 1~20자` | 계정 이름 형식 오류 | 허용 문자만 쓴다 |
| 404 `계정을 찾을 수 없습니다` | 계정이 없음 | 계정 관리에서 새로 만든다 |
| 이력 내려받기 404 | 저장된 이력이 없음 | 암기나 시험을 한 번 한 뒤 다시 받는다 |

## 5. 보안 주의

- 로컬 서버는 이 PC에서만 접속할 수 있다 (`127.0.0.1`).
- 웹은 온라인 검색 인증키를 `voca.db`에 저장하지 않는다 (v1.2). 예전 설정 화면에서 저장한 키가 옵션 행에 남아 있을 수 있으니 `voca.db` 파일을 다른 사람에게 보내지 않는다.
- 공용 PC에서는 계정 선택 화면만으로 보호되지 않는다. 같은 PC를 쓰는 사람은 다른 계정의 기록을 볼 수 있다.
- 학교 서버에 배포하면 접근 제한이 없다. 서버 배포 전에 운영 정의서 5.4의 미결 항목을 해결한다.

## 6. 점검 명령 (개발자용)

```
python -m unittest discover -s tests -v
```

웹 API 시나리오는 임시 폴더에서 실행되므로 실제 기록을 바꾸지 않는다.

## 7. 학교 서버 배포

- 서버 배포는 Dockerfile로 이미지를 만들어 실행한다. 절차, 환경 변수(`ALLOWED_HOSTS`, 이미지 기본값 `*`), 배포 전 확인 항목은 `운영_261118_배포·운영 정의서 v1.1.md` 5장을 따른다.
- 서버 배포본은 워커 1개로 실행한다. 여러 워커로 늘리면 진행 중 시험이 실패한다.
