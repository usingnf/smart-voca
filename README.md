# 스마트 보카 (웹 앱)

한글 사용자가 영어 단어를 익히고, 뜻이 비슷한 단어를 빠르게 찾기 위한 단어장 웹 앱입니다.
단어 등록, 암기, 시험, 일일 과제, 학습 진척 통계를 제공합니다. 이력과 설정은 SQLite(`voca.db`)에 저장합니다.

- 기본 실행 버전: 웹 (데스크톱 PyQt6 버전은 보조)
- 단어 원본: `data/voca.csv` (영단어 4,000개, 출처와 라이선스 표시 포함, `data/README.md` 참조)

## 실행 방법

### 1. 이 PC에서 실행 (개발·시연)

Python 3.11 기준입니다.

```
py -3.11 -m pip install -r requirements.txt
python web/run.py
```

또는 `웹실행.bat`을 더블클릭합니다. 브라우저가 `http://127.0.0.1:8765/`를 엽니다.

- 로그인 화면에서 **게스트로 시작**을 누르면 가입 없이 임시 계정으로 바로 쓸 수 있습니다. 게스트 계정은 이 브라우저에만 연결되어 로그아웃하면 다시 들어갈 수 없습니다.
- 사용자 데이터는 `data/voca.db`에 만들어집니다.
- 온라인 한영 보조 검색을 쓰려면 실행 전에 환경 변수 `KRDICT_API_KEY`를 설정합니다 (PowerShell: `$env:KRDICT_API_KEY="인증키"`).
- 위치를 바꾸려면 환경 변수 `DB_PATH`(DB 파일), `SMARTVOCA_DATA_DIR`(데이터 폴더)을 지정합니다.

### 2. Docker 이미지로 실행 (서버 배포와 같은 조건)

```
docker build -t voca-app .
docker volume create voca-data
docker run -p 8080:8080 -v voca-data:/data -e SECRET_KEY=<긴 무작위 값> voca-app
```

- 주소: `http://127.0.0.1:8080/`
- 컨테이너는 UID 10001로 실행하고, 쓰기는 `/data`(DB)와 `/tmp`만 합니다.
- 실행 중 인터넷이 필요 없습니다. 온라인 한영 검색만 실패하고 나머지 기능은 동작합니다.
- 설정 값: `ALLOWED_HOSTS`(받을 Host 이름, 이미지 기본값 `*`), `SECRET_KEY`(세션 쿠키 서명 키, 없으면 시작할 때 무작위 — 재시작하면 로그인이 끊깁니다).
- 온라인 한영 보조 검색을 쓰려면 환경 변수 `KRDICT_API_KEY`(국립국어원 한국어기초사전 인증키)를 주세요. 없으면 이 기능만 건너뜁니다. 인증키는 코드나 DB에 저장하지 않습니다.

```
docker run -p 8080:8080 -v voca-data:/data -e SECRET_KEY=<긴 무작위 값> -e KRDICT_API_KEY=<인증키> voca-app
```

### 3. 시험 실행

```
python -m unittest discover -s tests -v
```

웹 API 시나리오 테스트는 임시 폴더에서 돌아서 실제 학습 기록을 건드리지 않습니다.

## 구현한 요구사항

과제 요구사항(VOCA-FR) ID입니다. 요구사항 명세서 `docs/분석_261111_요구사항명세서 v1.6.md`의 4-2 대응표와 맞춥니다.

| ID | 요구사항 | 상태 |
|----|----------|------|
| VOCA-FR-001 | 영단어와 뜻을 직접 입력해 등록 | 구현 |
| VOCA-FR-002 | 단어 목록 보기, 수정·삭제 (추가한 단어만 수정·삭제 가능) | 구현 |
| VOCA-FR-003 | 영단어,뜻 CSV 일괄 등록 (기존·중복 단어는 건너뜀) | 구현 (제공 CSV로는 아직 미확인) |
| VOCA-FR-004 | 영단어 또는 뜻으로 검색 | 구현 |
| VOCA-FR-011 | 하루 학습량에 따라 1일차, 2일차 진도 | 구현 |
| VOCA-FR-012 | 그날의 단어를 한 장씩 보며 암기 (기본: 오늘 과제 단어) | 구현 |
| VOCA-FR-013 | 전날 외운 단어와 자주 틀린 단어를 그날 암기에 섞기 | 구현 |
| VOCA-FR-014 | 암기 이력(단어·시각·일차)을 DB에 기록 | 구현 |
| VOCA-FR-021 | 문제 수를 정하면 그 수만큼 출제 | 구현 |
| VOCA-FR-022 | 안 본 단어·오래된 단어·자주 틀린 단어를 더 많이 출제 | 구현 (웹) |
| VOCA-FR-023 | 출제 방향 선택 (영→한, 한→영, 섞기) | 구현 |
| VOCA-FR-024 | 출제 형식 (단답형, 4지선다형, OX형) | 구현 |
| VOCA-FR-025 | 채점 결과, 틀린 문항과 정답 표시 | 구현 |
| VOCA-FR-026 | 시험 이력을 문항 단위로 DB에 기록 | 구현 |
| VOCA-FR-031 | 진도 현황 (현재 일차, 암기 수 / 전체) | 구현 |
| VOCA-FR-032 | 시험 성적 추이 (회차별·날짜별 정답률) | 구현 |
| VOCA-FR-033 | 자주 틀리는 단어 목록 (상위 10개) | 구현 |
| VOCA-FR-034 | 통계는 DB 이력으로 계산 | 구현 |
| VOCA-FR-041 | 회원 가입, 로그인, 로그아웃 (도전) | 구현 (웹) |
| VOCA-FR-042 | 비밀번호 해시 저장 (도전) | 구현 (웹) |
| VOCA-FR-043 | 암기·시험 이력과 통계를 계정별로 분리 (도전) | 구현 (웹) |
| VOCA-FR-051 | 공개 계정의 학습 진척 통계 보기 (도전) | 구현 (웹) |
| VOCA-FR-052 | 공개 여부는 본인이 정함, 비공개 계정은 보이지 않음 (도전) | 구현 (웹) |
| VOCA-FR-053 | 다른 계정의 이력은 보기만 가능 (도전) | 구현 (웹) |
| VOCA-FR-061 | 하루 학습량, 복습 비율 설정 (도전) | 부분: 시험 기본값(문제 수·방향·형식)은 계정별이 아님 |
| VOCA-FR-062 | 설정을 DB에 저장하고 유지 (도전) | 부분: 시험 기본값은 전역 설정 |

과제 목록 밖의 추가 기능: 온라인 한영 보조 검색 (명세서 FR-12, 환경 변수 `KRDICT_API_KEY` 필요).

## 사용한 DB

**SQLite** (파일 `voca.db`). 계정, 상태, 추가 단어, 이력, 옵션을 한 파일에 저장합니다.
테이블은 처음 실행할 때 자동으로 만듭니다. 선택 이유는 `docs/설계_261118_아키텍처 결정 기록 v1.3.md`의 ADR-11을 참조합니다.

```

src/            업무 로직, 데이터 저장 (SQLite), 데스크톱 화면 (src/ui)
data/           단어 원본 (voca.csv)
tests/          단위 테스트, 웹 API 테스트
docs/           승인된 설계·운영·요구사항 문서
ai-agent/       AI 작업 기록과 보조 스크립트
Dockerfile      서버 배포 이미지
```
