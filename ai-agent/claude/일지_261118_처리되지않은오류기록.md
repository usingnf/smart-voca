# 작업 일지 — 처리되지 않은 오류 기록과 시험 기록 상수 통일

**작성일**: 2026-11-18 (작업 기록: 커밋 `874451b`, 2026-11-11 15:16)
**관련 문서**: `ai-agent/claude/261118_방법론문서화/설계_261118_아키텍처 결정 기록 v1.0.md` (ADR-06, ADR-08)

## 요청
처리되지 않은 오류를 사용자가 알 수 있도록 기록하고, 시험 기록 구분 상수를 한 곳에서 관리하도록 정리.

## 처리
- `src/crash_log.py` 신규: 잡히지 않은 예외를 `%LOCALAPPDATA%\SmartVoca\error.log`에 기록하고 안내 창 표시. Ctrl+C는 기본 처리.
- `src/main.py`: 앱 시작 시 `install_crash_handler()` 호출. exe는 콘솔이 없어 오류가 보이지 않던 문제를 해결하기 위함.
- `src/config.py`: `TEST_RECORD_KINDS` 정의, `ERROR_LOG_PATH` 추가.
- `src/session.py`, `src/report.py`: 중복 정의와 "과제시험" 문자열 직접 사용 제거.
- `tests/test_core.py`: 테스트 값을 상수로 바꿈.
- `tests/test_crash_log.py` 신규: 로그 기록, 쓰기 실패 처리, Ctrl+C 처리 테스트 4개.

## 결과
- 단위 테스트 71개 통과 (2026-11-18 실행).
- exe 재빌드는 이 커밋 이후 수행하지 않음. `dist/SmartVoca.exe`는 15:11 빌드로 이 기능이 빠져 있음.

## 확인 필요
- PyQt 슬롯에서 발생한 예외는 안내 창을 띄운 뒤 Qt가 앱을 종료할 수 있음. 실제 exe 실행으로 확인 필요 (ADR-06).

## 후속 작업
- 재빌드 후 강제 오류 확인 (작업 계획서 T-1, T-2).
- `session.py` 빈 줄과 import 순서 정리 (T-5).
- 테스트 출력의 오류 로그 잡음 정리 (T-6).
