# 작업 일지 — FR-12 온라인 한영 보조 검색

**작성일**: 2026-10-28
**관련 요구사항**: FR-12 (CLAUDE.md 요구사항 표 및 "온라인 한영 보조 검색 규칙")

## 요청
한영 뜻 온라인 검색(무료, 기존 검색의 보조, 오프라인 시 로컬 결과만) 추가. FR-12로 요구사항에 등록하고 외부 호출 허용.

## 처리
- 후보 조사: 국립국어원 한국어기초사전 검색 API 선정 (공식 안내 페이지 확인, 한→영 번역 `translated=y&trans_lang=1`).
- CLAUDE.md: FR-12 표 항목과 세부 규칙 추가.
- `src/online_dict.py` 신규: 요청 주소 생성, XML 해석, 시간 초과 5초, 오프라인·HTTP 오류 처리.
- `src/settings.py`: `krdict_api_key` 항목 추가 (코드에 키를 넣지 않음, settings.json에서 입력).
- `src/ui/study_pages.py`: `SearchPage`에 온라인 참고 영역 추가. 한글 검색어만 조회, 600ms 디바운스, `QThread` 백그라운드 실행, 메모리 캐시.
- `src/ui/main_window.py`: 설정 적용 시 검색 화면에 키 전달.
- `tests/test_online_dict.py` 신규: 요청 주소, XML 해석(정상·빈 결과·오류 응답), 키 없음·오프라인·시간 초과·HTTP 오류, 설정 키 처리.
- 실제 호출 1회: 더미 키(32자리 0)로 요청. 응답은 HTTP 200에 `<error><error_code>020</error_code><message>Unregistered key</message></error>`. 이 형식에 맞춰 해석기를 수정하고 테스트를 추가함.

## 결과
- 단위 테스트 32개 통과 (`python -m unittest discover -s tests`).
- `ui.main_window` 임포트 확인 (offscreen).
- 실제 인증키로 실검색 확인 (2026-10-28): `data/settings.json`에 키 저장 후 호출.
  - 사과 → 6건 (apple, apology, apple tree, offer an apology, apologize, written apology). 앱은 상위 5건 표시.
  - 바나나 → 1건 (banana).
  - 없는단어zzz → 결과 없음 (오류 아님).
- 성공 응답 XML 구조(`channel/item/sense/translation/trans_word`)가 파서와 일치함을 확인.
- 앱 화면(검색 탭 온라인 영역) 실제 동작과 오프라인 전환은 아직 직접 확인하지 않음.

## 추가 작업 (옵션 설정·빌드)

### 온라인 검색 on/off 옵션
- 요청: 옵션에서 온라인 한→영 기능을 켜고 끌 수 있게 함.
- 처리: `AppSettings.online_lookup_enabled` 추가(기본 True). 옵션 화면에 체크박스 추가. 끄면 검색 화면에서 조회를 시작하지 않고 온라인 영역을 비움.
- 함께 고친 버그: 옵션 값을 바꿀 때 `current_values()`가 입력 칸 값만으로 설정을 새로 만들어 `krdict_api_key`와 창 크기가 `settings.json`에서 사라지던 문제. 현재 설정을 복사한 뒤 바뀐 칸만 덮어쓰도록 수정. "기본값으로 되돌리기"도 키와 창 크기를 유지.

### 옵션 화면의 인증키 확인·입력
- 요청: 옵션에서 현재 키를 확인하고, 키를 입력할 수 있게 함.
- 처리: 키 입력칸(기본 가림 표시), "보기" 체크박스, "저장" 버튼 추가. 형식은 영문·숫자 32자리(공식 안내 기준)로 검증. 빈 값으로 저장하면 키 삭제.
