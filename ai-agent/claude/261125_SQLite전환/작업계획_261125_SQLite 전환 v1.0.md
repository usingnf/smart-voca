# 작업 계획 — 사용자 데이터 파일 저장소를 SQLite로 전환

**파일 위치**: `ai-agent/claude/261125_SQLite전환/작업계획_261125_SQLite 전환 v1.0.md`
**작성일**: 2026-11-25
**버전**: v1.0
**설명**: 계정·단어·이력·상태·옵션 저장소를 파일(JSON/CSV)에서 SQLite(`voca.db`)로 바꾸는 작업의 범위와 결정 기록

---

## 1. 배경

- 학교 서버 배포 조건 5: DB는 SQLite, 파일 위치는 환경 변수 `DB_PATH`(값 `/data/voca.db`).
- 현재 저장 방식: 계정 폴더 `users/<계정>/state.json`, `words.csv`, `history.csv` + 프로그램 폴더 `settings.json`.
- 데스크톱 앱(PyQt6)과 웹 앱(FastAPI)이 같은 `src/user_store.py`, `src/settings.py`, `src/session.py`를 쓴다.

## 2. 대안과 결정

| 대안 | 내용 | 판단 |
|---|---|---|
| A. 전체 전환 | 계정·단어·이력·상태·옵션을 `voca.db`에 저장 | **채택** — 조건 5 충족, 저장 코드가 한 벌로 줄어듦 |
| B. 경로만 변경 | 파일 저장 유지, 위치만 `/data` | 기각 — 조건 5 미충족 |

**결정 근거**: 사용자가 A안을 선택했다 (2026-11-25).

**범위 결정**
- 기본 단어 4,000개(`data/voca.csv`)는 읽기 전용 기준 데이터라 CSV로 둔다. 사용자 데이터만 DB로 옮긴다.
- 데스크톱 앱도 같은 DB를 쓴다. 기본 위치는 exe 옆 `voca.db`(`BASE_DIR/voca.db`), 환경 변수 `DB_PATH`로 바꿀 수 있다.
- 기존 파일 데이터는 변환 스크립트로 옮긴다. 원본 파일은 지우지 않는다.

## 3. 테이블 설계

| 테이블 | 내용 | 비고 |
|---|---|---|
| `users` | 계정 키, 만든 시각 | 다른 테이블의 부모 (ON DELETE CASCADE) |
| `user_state` | 계정 상태 JSON (과제, 대기열, 오답률 통계, 암기 기록, 즐겨찾기) | 상태 구조는 기존 `state.json`과 같게 유지 (daily.py 수정 없음) |
| `custom_words` | 계정별 추가 단어 (뜻·동의어는 JSON 문자열) | 기본 키 (계정, 단어) |
| `history` | 이력 한 행 = 한 줄 | 열 이름은 영문, 조회 결과는 기존 한글 키 그대로 반환 |
| `app_settings` | 옵션 JSON 한 행 | `CHECK (id = 1)` |

## 4. 파일별 작업

| 파일 | 작업 |
|---|---|
| `src/config.py` | `DB_PATH` 추가 (환경 변수 `DB_PATH`, 기본 `BASE_DIR/voca.db`). `USERS_DIR` 제거 |
| `src/database.py` (신규) | 연결, 트랜잭션, 테이블 생성(`ensure_schema`) |
| `src/user_store.py` | 파일 입출력을 SQL로 교체. 공개 메서드 이름은 최대한 유지 |
| `src/settings.py` | `load_settings`, `save_settings`를 DB 기반으로 변경. `SETTINGS_PATH` 제거 |
| `src/session.py` | `export_history`를 파일 복사 대신 CSV 바이트 생성으로 변경 |
| `web/app.py` | 계정 존재 확인, 이력 내보내기, 옵션 호출부 수정 |
| `src/ui/options_page.py`, `src/online_dict.py`, `src/ui/main_window.py`, `src/ui/test_pages.py` | 안내 문구의 `settings.json`을 실제 저장 위치에 맞게 수정 |
| `tests/test_core.py` | `StoreTests`를 임시 DB 기준으로 수정, 옵션 저장 테스트 추가 |
| `ai-agent/scripts/261125-파일저장소를SQLite로옮기기.py` (신규, 1회성) | 기존 `users/`, `settings.json`을 `voca.db`로 옮김 |
| `.gitignore` | `*.db` 추가 |

## 5. 검증 계획

1. 단위 테스트 전체 실행 (`python -m unittest discover -s tests -v`).
2. 웹 API 시나리오 테스트 (임시 데이터 폴더에서 DB 자동 생성).
3. 변환 스크립트를 `data/`의 **복사본**에 실행해 계정 수·이력 수·옵션을 비교.
4. 실제 `data/`는 건드리지 않는다. 변환 실행은 사용자 확인 후 진행한다.
