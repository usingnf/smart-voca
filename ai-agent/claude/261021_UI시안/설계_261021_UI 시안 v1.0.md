# UI 시안 설계 메모

**파일 위치**: `ai-agent/claude/261021_UI시안/설계_261021_UI 시안 v1.0.md`
**작성일**: 2026-10-21
**버전**: v1.0
**설명**: PyQt6 UI 시안의 구성, 화면별 기능, 캡처 방법을 기록한다. 사용자 검토 후 수정한다.

---

## 1. 시안 구성

- 실행 파일: `src/ui_mockup.py` (샘플 데이터만 사용, 실제 저장·채점 로직 없음)
- 캡처 스크립트: `script/capture_screens.py` → `images/` 에 화면별 PNG 저장
- 창 구조: 왼쪽 메뉴(QListWidget 160px) + 오른쪽 작업 영역(QStackedWidget), 고정 크기 900×560
- 글꼴: 맑은 고딕 10pt (앱 전체 지정)
- 시작 시: 계정 선택 창(사용자명 입력) → 메인 창

## 2. 화면별 구성

| 메뉴 | 파일 | 주요 요소 | 요구사항 |
|------|------|-----------|----------|
| 암기 | `시안_01_암기.png` | 방향 선택, 문제 단어 표시, [열기], [다음 단어] | FR-02 |
| 시험 | `시안_02_시험.png` | 문제 수(5~50, 기본 20), 방향, 유형 체크박스, [시험 시작], 결과 표 | FR-03, FR-06, FR-07 |
| 과제 | `시안_03_과제.png` | 과제 구성(복습·신규), 완수 기준, 상태, [과제 시험 시작] | FR-04 |
| 단어 추가 | `시안_04_단어 추가.png` | 영단어·한글 뜻 입력, [추가] | FR-01 |
| 유사 의미 검색 | `시안_05_유사 의미 검색.png` | 검색어 입력(영단어·한글 뜻), [검색], 결과 목록 | FR-10 |
| 보고서 | `시안_06_보고서.png` | 기간 선택, 과제 이수율·암기 수, 오답률 상위 표, [HTML 보고서 열기] | FR-09 |
| 계정 관리 | `시안_07_계정 관리.png` | [기록 초기화], [계정 삭제] → 확인 창 | FR-11 |

계정 관리 화면의 확인 창과 계정 선택 창은 PNG에 포함되지 않는다 (대화상자는 캡처 대상이 아님).

## 3. 시안에서 임의로 정한 부분 (수정 요청 대상)

- 메뉴 항목 순서와 이름
- 시험 결과 화면의 열 구성 (단어, 내 답, 정답, 결과)
- 과제 화면의 문구 ("과제 20개 (복습 7 / 신규 13)")는 예시 값이다
- 보고서 화면 문구의 샘플 수치 (60%, 35개, 50%)는 예시 값이다
- 계정 관리 확인 창 문구

## 4. 실행·캡처 방법

- 실행: `python src/ui_mockup.py` (로그인 창에 사용자명 입력)
- 캡처: `QT_QPA_PLATFORM=windows python script/capture_screens.py`
  - `offscreen` 모드에서는 Windows 글꼴 목록을 읽지 못해 한글이 네모로 나온다. 그래서 `windows` 모드를 쓴다.
