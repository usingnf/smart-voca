## 1. 앱 아이콘
- `ai-agent/scripts/261111-앱아이콘생성.py` 신규 (1회성 스크립트, PIL로 그림).
  - 디자인: 파란 그라데이션 둥근 사각형, 펼친 책, 큰 영문자 "A", 주황 원 안의 "가".
  - 산출물: `src/assets/SmartVoca.ico` (16~256px 다중 크기), `src/assets/SmartVoca_preview.png`.
- 시행착오
  - 한글 "가"를 Arial로 그려 두부(□) 글자가 나옴 → 맑은 고딕 굵은체(`malgunbd.ttf`)로 변경.
  - 왼쪽 페이지 줄이 "A"와 겹침 → 줄 제거.
- `src/config.py`: `APP_ICON_PATH` 추가. `src/main.py`: 경로가 있으면 `QApplication.setWindowIcon` (개발 실행용). exe에서는 파일이 없으므로 exe 자체 아이콘이 쓰임.
- 빌드 시 `--icon` 경로는 PyInstaller가 spec 폴더(`build/`) 기준으로 해석하여 절대경로가 필요했음 → 이후 `../src/assets/SmartVoca.ico` 상대경로로 정함 (이식성 확보). CLAUDE.md 빌드 명령 갱신.
- 검증: exe에서 `ExtractAssociatedIcon`으로 추출한 아이콘 픽셀이 새 디자인과 일치함.

## 2. 기능·UI 개선 찾기
- 기존 화면 코드(`src/ui/*.py`)를 읽고 항목을 나열함 (1~15번). 코드 읽기 기반이며 실제 실행으로 재현하지 않은 항목이 일부 있음 (3, 6번).

## 3. 1~6번 처리 (동작·안정성)
1. 과제 시험 중도 종료 안내: 과제 시험은 "오늘 과제가 미이수로 기록되고 다음 날 복습으로 이어집니다" 문구 사용 (`QuizDialog(abort_message=...)`).
2. 온라인 조회 오류는 캐시하지 않음 → 같은 검색어를 다시 입력하면 재조회.
3. `SearchPage.shutdown()` 추가, 창 닫을 때 실행 중인 조회 스레드를 최대 6초 대기 (조회 제한 5초보다 길게).
4. 암기 화면: 즐겨찾기가 없으면 전체 단어로 바뀌었다는 안내 표시.
5. `record_memorize`: 같은 날 같은 단어는 이력을 한 번만 남김 (동작 변경 — 열어 본 횟수는 이력에 남지 않음).
6. 연타 중복 제출 방지.
   - 시행착오: 문항별 플래그를 먼저 시도했으나, 답 제출 시 다음 문항 보기가 동기적으로 다시 열려서 더블클릭이 다음 문항을 건너뛰는 문제가 생김 (테스트로 발견).
   - 최종: 제출 후 `ANSWER_COOLDOWN_MS = 250` 동안 입력 무시.

## 4. 7~14번 처리 (UI)
7. 결과 화면 "오답만 다시 풀기": `QuizDialog(allow_retest=True)`일 때만 표시. 시험 설정 화면(`TestPage._run_quiz`)이 틀린 단어로 재시험을 연다. 과제 시험에는 표시하지 않음.
8. 키보드 조작
   - 암기: Space·Enter는 열기 (이미 열었으면 다음 단어), → 는 다음 단어. `QShortcut`, 범위는 `WidgetWithChildrenShortcut`.
   - 검색: 입력 칸에서 Enter·↓ → 결과 표 첫 행, 표에서 Esc → 입력 칸 (`eventFilter`).
9. 메뉴 묶기: `MENU_LAYOUT`으로 "학습"/"관리" 묶음 제목(선택 불가) 추가, 화면 번호는 항목 데이터로 보관. 아이콘은 유니코드 기호 (이미지 아님).
10. 툴팁: 암기, 시험 설정, 단어 추가, 검색, 옵션 항목.
11. 과제 화면: 상태별 안내 문구 (`ASSIGNMENT_HINTS`), 비활성 버튼에 이유 툴팁.
12. 보고서 그래프: 전체는 최근 14일, 기간 선택 시 그 기간 (최대 60일). 제목도 기간에 맞춤.
13. 단어 추가: 입력 중 이미 있는 단어이면 칸 아래 안내. 요구사항("경고를 띄운 뒤 뜻을 합친다")을 지키기 위해 저장 시 모달 경고는 유지함 (화면 개선 항목을 그대로 적용하지 않은 부분). 추가 후 단어 칸으로 포커스.
14. 시험 조건 기억: `AppSettings`에 `exam_kinds`, `exam_pos_keys`, `exam_favorites_only` 추가 (`settings.json`). 유형·품사는 최소 1개가 켜져 있어야 함 (모두 끄면 저장 시 기본값으로 바뀌고 화면도 되돌아가는 문제 방지).
- 시행착오: `python3`가 Windows 스텁이라 패치 스크립트가 실행되지 않음 → Edit 도구로 직접 수정.

## 5. 검증
- 단위 테스트 `python -m unittest discover -s tests`: **67개 통과** (기존 43 + 신규 `tests/test_ui_fixes.py`).
  - 신규 테스트는 가짜 세션·저장소를 써서 실제 `data/` 폴더에 쓰지 않음.
  - 중도 종료 문구, 온라인 오류 캐시, 이력 중복, 연타 방지, 재시험 버튼, 조건 기억, 단어 추가 안내, 단축키 동작, 메뉴 화면 번호 등.
- 앱 실행 확인: `QT_QPA_PLATFORM=offscreen`으로 개발 실행과 exe 모두 8초 동안 시작 오류 없이 로그인 창에서 대기함.
- **실제 화면 모양, 단축키 체감, 아이콘의 작은 크기 가독성은 직접 확인하지 않음.**

## 7. 상단 표시줄·작업표시줄·프로세스 아이콘 (추가 작업)
- 시작 상태 확인: 로그인 창의 `WM_GETICON` 값이 0 → 창 아이콘이 설정되지 않았음. 원인은 exe에서 `APP_ICON_PATH`가 `_MEIPASS` 안의 없는 파일을 가리킨 것.
- `src/config.py`: `resource_path()` 추가 (`_MEIPASS` 또는 소스 폴더 기준). `APP_USER_MODEL_ID = "SmartVoca.Desktop"` 추가.
- `src/main.py`: `set_windows_app_id()`로 작업표시줄 식별자 지정 (QApplication 생성 전). 기본 창 아이콘을 `app.setWindowIcon`으로 지정하여 모든 창에 적용.
- `packaging/version_info.txt` 신규: FileDescription·ProductName을 "스마트 보카"로 지정 (작업 관리자 표시 이름).
- 빌드: `--add-data "../src/assets/SmartVoca.ico;assets"`, `--version-file ../packaging/version_info.txt` 추가. 옵션 경로는 spec 폴더 기준이라 `../` 사용. CLAUDE.md 빌드 명령 갱신.
- 검증: 재빌드한 exe에서 로그인 창의 WM_GETICON이 0이 아닌 값을 반환하고, 큰 아이콘 픽셀이 새 디자인과 일치함. 파일 속성 설명은 "스마트 보카".
- 확인하지 못한 것: 작업표시줄 그룹 표시와 작업 관리자의 실제 화면 모양. 개발 실행 경로(`python src/main.py`)의 창 아이콘도 코드상으로만 확인.
- 시행착오: `--add-data`도 `--icon`과 같이 spec 폴더 기준이어서 처음에 빌드가 실패함 → `../` 상대경로로 수정.
